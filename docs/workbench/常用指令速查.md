# 常用指令速查

| 要做什么 | 直接复制这句话并附材料 |
| --- | --- |
| 编剧 | 根据这个设定写完整短片剧本，未锁定细节你合理决定。 |
| 分镜 | 根据确认剧本写30秒Seedance 2.5完整提示词，台词逐字保留，机位和切点你决定。 |
| 摄影优化 | 只优化第2、4板，剧情/台词/服装/@标签不改；有必要可重分时并说明。 |
| 时长锁 | 总长保持24秒，不拆条；放杯至收手局部必须真实不切。 |
| 提示词审查 | 只检查相邻两条的真实末态/初态、轴线、道具和声源，不改稿。 |
| 局部修复 | 只改下一条画面，上一条全文及台词/时间/标签保持原样。 |
| 海报 | 按正式剧名、剧情和人物参考写3:4海外短剧海报提示词，服装按参考。 |
| 可编辑排版 | 用这些确认文字和主视觉做可编辑海报，精确置字并检查实际预览。 |
| 台词 | 按集原样提取纯台词，不翻译、不润色、不去重，不发布在线文档。 |
| 配乐 | 根据剧情时间线给英文Style/Structure，重要对白处停音乐但保留环境/动作音。 |
| 音频转镜头 | 从实际听到的声音提取节奏和情绪，再写视觉提示词，未听到的标未知。 |
| 后期 | 在工程副本中按这份变更表修改，保留源媒体并验证重开/导出。 |
| 实片QC | 对照最新提示词检查实际视频，标时间段和证据，给最低成本修复。 |
| 广告 | 只基于这些真实卖点写广告脚本，不补造功效或评价。 |
| UI | 保留当前技术栈和品牌，优化这个核心用户流程并检查窄屏/错误状态。 |
| 项目恢复 | 这是当前快照和最新完整稿，只继续下一步，不重新立项。 |

方括号或“这些”需要实际材料支持。正常任务不必完整填写表格；目标、范围、保留项三项清楚就能推进。

Gemini配乐：“根据分镜表第5集写纯器乐背景音乐，给一块完整英文提示词，内部保留Style/Structure；中文说明重要台词哪里收薄或停音乐。不编秒数，不实际生成。”

日常短句可用：“第5集配乐”“下一集也这样”“给2—4集人物介绍卡”“只改第3格”“这张只改光”“按刚才的范围删那四段”。会沿用当前确认材料与锁；有歧义只问必要项，不自动提交收费生成。

整份复制：“给我整份复制版，最终正文放进一个代码块，保留必要设置、分段和编号，说明放块外。”长版固定指令见《最简单使用方式》的“长文字与整份复制版”；短句调用继续有效。
