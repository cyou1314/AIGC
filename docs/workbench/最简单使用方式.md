# 最简单的使用方式

## 第一次

在当前聊天启用“Xan”。说：“检查本会话可用能力；不联网扫服务、不调用付费生成。然后按我的任务直接做。”预检只检查当前任务相关能力。

## 干活时一句短话加材料即可

有当前材料和明确语境时，直接说“第5集配乐”“下一集也这样”“只改第3格”即可。工作台沿用本项目已确认设置，不要求复述长指令。新材料/新目标才补那部分，源版本或范围不明确时只问必要缺项。

需要写清复杂新任务时，可选用：

    我要：[最终结果]；范围：[集/板/行/时间段]；必须保留：[台词/人物/资产/时长等]。

其余可以留空让工作台判断。不必选技能，不必完整填表。

例：
- “根据附件剧本，优化第1集前两板，机位/切点你决定，台词和标签不改，给完整提示词。”
- “改成30秒，总长不能变；救人这个动作组必须真实不切，其他你决定。”
- “检查这两条的末态/初态、道具与口型，只报告问题。”
- “按集原样提取台词，重复保留，不润色，不上传文档。”
- “按剧情写3:4海外短剧海报提示词，正式剧名逐字保留，衣服按参考。”
- “给这段剧情Style/Structure配乐方案，重要对白只停音乐，保留呼吸和拟音。”
- “读取分镜第5集，给我Gemini一块可直接粘贴的纯器乐提示词，不要哼唱，没有可靠时码就按剧情节拍。”

## 长文字与整份复制版

直接说“给我整份复制版”或“长文字一键复制”。单份最终正文放在一个代码块，保留分段、时码和镜头编号，说明与检查结果放块外；不必逐段拼接。多集/多条实际分别投喂时可按单元分块，明确要整份就合并并标记边界。复制按钮由聊天界面提供，技能控制的是代码块和内容组织，不额外安装按钮。

需要较完整的固定要求时，可整块复制下面这一段，再附本轮材料与任务；日常仍可只说短句：

```text
请结合我本轮的话、附件和当前已确认的项目设置，判断我要的最终结果，直接进入最合适的一个主模块，不要求我报技能名。能从上下文确定的范围、平台、风格和保留项继续沿用；遇到真正影响完成的歧义，只问必要缺项。

先使用当前模块的方法，只在任务需要时读取相关专业参考；已读且未变的规则不重复读取。保留必要的专业分析和检查，不用精简资料的方式降低质量。普通制作不启动技能维护、重新打包或全仓测试。

直接交付一份完整可用的最终稿。需要复制使用的长篇正文集中放进一个代码块，保留段落、时码、镜头编号及必要的全局设置，不拆成需要我手动拼接的碎片，不用“同上”或省略号替代必要内容。说明、假设和检查结果放在代码块外，不混入最终投喂内容。多集、多条或平台分输入框时保留清楚的单元与字段边界；我说“整份复制版”时，把选中范围的完整正文合在一块。

保护已确认的剧情、逐字对白、角色身份、服装、资产标签、时长和声音要求；本轮明确授权的修改按实际范围完成。只要提示词就交提示词，实际生成与文件操作按本轮要求及现有工具能力执行，未执行的不说已完成。优先给一个符合当前要求、质量与可实现性合理的方案。

本轮任务：在这里写我要做的事，并附材料。
```

## 完整项目

    这是目标、素材和最新状态。你规划当前最合适路线，每次推进当前一步；已确认内容继续沿用，只有影响剧情、硬锁或执行的关键缺失才问。

结束本轮说“给我项目快照”。下次聊天附快照和必要源文件继续。插件不凭空继承旧聊天/本地账号。

## 实际生成与后期交接

以后说“第5集配乐”等短句时，每份配乐提示词会在复制块第一行原样加入：“请根据以下风格和结构生成短剧背景音乐。只要纯器乐，不要演唱、说话、哼唱或合唱。”随后写Style/Structure正文；固定中文首句保留，正文默认英文。该开头属于提示词内容，不代表已经实际生成音乐。

需要实际生成时明确说明并提供源文件/已连接工具；只预检当前依赖，有能力就执行并验证，没有仍先交完整生成材料与真实缺口。剪映后期直接说“给我手动剪映剪辑表、素材清单和字幕”；不使用剪映/CapCut CLI，不要求安装它，也不声称已改工程。FFmpeg只按具体媒体任务需要使用。普通GPT上传知识不能替代外部生成服务。

推荐先从“剧本→分镜/提示词→只审查”这条文字路线开始，不用先连接付费工具。实际媒体执行在连接好对应工具后使用，不把无法保证的全局最优或永不卡顿当承诺。
