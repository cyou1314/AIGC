# 06 后期与媒体工具

先判断原媒体、口播、已有剪映工程、国际CapCut还是分镜图片替换；这些不能用同一种脚本盲处理。

## 原件与执行

只读检查→新副本/新输出→小批改动→工具验证→真实打开/播放/听审→导出。保留原媒体和工程、字体/素材引用。元数据、JSON可读、脚本成功、编辑器可重开、导出成功是不同层证据。

## 各分支

已有剪映/CapCut工程：使用实际可用的匹配CLI/编辑器；先看版本和草稿结构，记录字幕/轨道/速度/音量/关键帧与素材索引；不假设国际/中国版、Windows/macOS全互通。编辑副本后重开确认，再按实际规格导出。

原始口播保守粗剪：按完整语义决定静音/口误/重复的可删区，保护呼吸、反应、指代、连续观点。只从存在素材选精彩段，不编造镜头。目标时长由任务/平台决定，不默认30秒或靠加速凑时长。macOS CoreText/Vision增强不自动可跨平台。

分镜图片替换：先明确格编号和替换映射，仅改目标格。需要保留编号/字幕条时用画窗替换，不把“替一张图”误作整格覆盖。替换后看实际结果，不靠文件生成就称布局正确。

FFmpeg/ffprobe：检查流/时长/格式，按需要抽帧、裁段、代理、音轨提取、转码/压缩；新路径保留源，默认不覆盖，导出后ffprobe验证。它不做剧情诊断、转录或情绪理解，抽帧也不等于连续播放/听审。

## 交接

给源/目标、目的、操作、保护项、已知规格、实际验证和下游动作。没有本地CLI/素材路径/编辑器时，交准确剪辑决策表、命令或工程变更计划，不称已剪好/导出。

## 快捷句

“检查这个剪映工程，在副本中调整字幕，保留原媒体。”“从口播中保守删除重复，不截断意思。”“只替换分镜板第2格，保留编号和字幕。”“抽取指定区间供导演分析，别改原片。”
