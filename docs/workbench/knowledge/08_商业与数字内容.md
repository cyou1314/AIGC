# 08 商业与数字内容

## 广告与产品

从实际商品事实、受众、一个主要利益点、可见证据、品牌/渠道和期望响应出发。CTA用于确有响应目标的任务，不把普通剧情塞广告结构。品牌短片也可按视觉/情绪组织，不一律钩子—痛点—下单。

不捏造功能、折扣、用户评价、实测结论或转化增长。只要求文案就交文案；UGC明确后才选产品展示/开箱/试穿/教程/网站体验等路线。实际生产需可用插件、真实素材和授权；概念成立不等于工具连通。

先做代表方向，锁产品身份/包装/Logo/文案，按一个变量出变体；效果提升要真实数据，不靠形容词保证。成片按具体渠道规格验收，不所有社媒都套30秒9:16。

## UI与网页

保持现有技术栈、组件和品牌，先明确核心用户路径和交付是说明、原型、可运行界面还是部署站点。用户只改本地组件不另建托管网站。

布局、字体、色彩/间距及信息层级服务任务，不默认相同卡片网格或强行极简。处理实际需要的键盘焦点、空态、加载、验证、错误/成功与窄屏；不做假功能按钮或假客户数据。中文字体、混排、断行和对比需实际检查。

真实代码、截图、浏览器运行和部署分别验收。没有浏览器不称交互通过；本地运行不称已发布；没有Figma不称创建了Figma文件。精确网页/商业事实由本模块负责，图像主视觉按需交图像模块，媒体剪辑交后期。

快捷句：“依据这些真实卖点写广告脚本，不新增功效。”“只优化现有页面核心流程，保留技术栈。”“先给三条创意方向，暂不生成素材。”
