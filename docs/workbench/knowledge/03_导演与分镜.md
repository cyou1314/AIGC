# 03 导演与分镜

解说漫分支区分VO、现场对白、媒体声和字幕；声音与画面双轨推进，一段VO可跨切镜或长镜节拍，原文与声音身份连续。按实际声音估时，所有集保持2.5规划，不承接“第16集切回2.0”、30秒15镜或固定近景配额。公司八字段JSON只在导入合同要求时使用，校验原文覆盖、声源、资产和时间轴，不以“N=末秒+1”制造空缺。完整方法见narrated-storyboards-and-company-json参考。

适用：确认剧情转分镜、参考镜头分析、Seedance 2.5视频提示词、授权摄影优化。公司导演优化v0.4.0与提示词审查已整合；一板/生成片段不等于一个摄影镜头。

## 观看先于摄影

先确定当前事件的变化证据、揭示顺序、人物反应和下一注意对象，再选关系/动作/道具/反应视角。不要逐句配近景、强制远景开场、强制景别阶梯或按总时长平均分镜。相邻镜头对比主体、占比、角度和构图；同主体近似机位/景别无收益易跳切，有意重复可成立。30度原则是参考，不能替代轴线、动作和观看理由。

按剧情判断可压缩的重复、需要推进的行动和应停留阅读的证据或反应；让节奏与观看作用匹配，匀速、长等待或不切镜有剧情依据时也可成立。比较固定、人物调度、运动、移焦和切镜带来的可见信息与时间代价；区分人物、摄影机、剪辑和播放速度。方案数量以用户要求为准，不用后期变速掩盖时间冲突。

提供实片并要求排查运镜时，观察相应时段主体、前后景、遮挡和地标的连续变化。放大不单独证明推近，横向变化不单独证明横移，人物转面不单独证明环绕；证据不足时不猜根因。观察与成片验收分开，未实际生成不称对照试验已完成。

三类连接：真实连续镜头写起始机位→触发→实际路径/朝向/焦点/主体→减速停留→终点；可见切镜写前镜线索→具体切点→后镜接收；隐藏转换写进入→足够覆盖→获准转换→显露。观看流畅不等于相机连续，声音桥不证明画面无切；真实不切锁内不能放隐藏切或生产拼接。

世界位置与画面投影分开。合法反打改变脸的可见面和前后景，不自动让角色转身/换手；只有持续摄影才需要相机实际走到新观察点。关键接触、交付、释放、施力和结果须有可读证据，动作匹配可以跨镜完成，不强求每个起手独占镜头。

## 时间与模式

规划目标Seedance 2.5，公司每生成单元4–30秒，内部镜头没有4秒下限；实际入口能力另验。当前明确总长/动作时刻/不拆/真实一镜锁优先，否则有作用的内容必要时可重分时/扩时/拆成够用的最少片段，并说明源→新分配。每条本地时间从0完整覆盖，跨条状态/全局映射另交。无实录对白时标估算，不用加速解冲突。

用实际素材选择文生视频、图生、首尾帧、参考、修改或延展；没有参考不编造@图名。已有标签逐字保留；资产的身份、服装、场景、动作、运镜、声音职责分开。已接受实际尾帧管暂态，身份图管长期外观。

## 提示词交付

默认一版完整版：按任务设置全局人物/场景/道具/风格/声音/连续性/避免项；逐镜包含规划时间、起始画面、主体动作、具体机位/路径或切点、必要声源/逐字对白与窗口、关键反应和尾态。共享规则不逐镜复述。假设/检查说明在投喂正文外。跨条独立使用时给足必要全局信息，不能“同上”丢约束。

多人对白核对实际声源、OS/VO、可读脸、前景身份、唯一口型者与静默听者。切看听者可以延续原说话者声音，不把听者当说话者。一般“流畅”不强制跟拍；复杂动作不自动拆成等长条。

快捷句：“按公司标准优化第2、4板，剧情/台词/标签不改。”“这一动作组真实不切，其他你决定。”“写30秒完整版，不给精简版。”
