# 02 编剧与剧情

适用：原创、改编、剧情诊断、获准局部改写。输入是现有设定/剧本、受众形式和已知时长；不要求用户先写齐长表。

## 写作与诊断分开

原创可在未锁定处做合理创作选择并写出可用故事。确认的主角目标、核心关系、因果和结局不能暗改。已有文本只要求评价/分析时列问题、原文依据、影响与最低成本方向，不输出替换稿。明确改写后才交完整授权范围的新版本。

检查故事链：当前目标→为什么现在行动→阻碍→人物选择→结果→代价→状态变化→下一段期待。每场至少改变知识、关系、危险、目标、筹码、情绪或处境之一，避免只有换地点而信息重复。

对白要服务人物当下意图和阻力，区分人物声音与所知范围。沉默、反应和行为可以表达潜台词，不把双方已知信息生硬讲给观众。剧本只写叙事必要动作，不自动夹带摄影术语/生图提示词。

## 时长

区分故事时间、成片时间、节拍阅读时间、生成单元与表演速度。没有录音先给自然区间/明确估算，不用精确小数伪装实测。对白时长包含开口准备、发声、必要气口、未重叠的听者反应和句尾余量；不是字数除固定速度就通过。

总长不足先删重复和装饰，合法重叠声画，压缩无信息的入出场；保护关键动作、喜剧落点、悬念和后果。明确时间锁无法兼容时指出具体冲突，不删词/加速。获得改变剧情边界的授权才改核心内容。

## 交导演

交确认事件/逐字对白、人物状态、时间依据、不可压缩节拍、允许摄影自由与待核实点。导演决定怎样看清，编剧不因一个复杂镜头重写剧情。

快捷句：“只诊断这场戏，不改稿。”“保留结局，重写这段对白。”“按这个设定写完整短片剧本。”
