# 05 声音与台词

四类任务分开：已有音频转文字；现有文本按集整理；声音内容/节奏转视觉；原创配音/配乐/音效方案或真实音频生成。转录可用不证明TTS或音乐服务可用。

## 台词提取

XLSX优先对应台词列，确认章节/分镜与行顺序，合并章节空白向下承接；只有提示词列不能把整格当台词。TXT默认每行是台词，只有明确角色标签可剥离。保留原句、大小写、重音、重复、顺序和集数，不翻译/润色/去重，不写回源表。

检查先给文件/集数/条数/标点建议/数字相关统计，并展示待改原文→建议具体差异。只应用本次已授权标点/数字项；原样提取或无建议无需额外确认。不支持数字读法保留，日期/金额/小数/时间/电话/编号/牌面/骰子分别判断，数词语言不能猜。英语、巴西葡语、墨西哥西语子集不是所有语法/数值全支持。

每集一个标题和一个text代码块，每条一行，正文不夹角色/镜号/解释。确认对当前来源与建议有效；--confirmed不是授权替代。不默认写飞书。包内纯Python辅助可在允许执行且依赖可用时运行，XML草稿不等于在线文档。

## 转录与音频转视觉

保留可听对白、必要重复、笑/叹/气口和可靠时间。区分实际听到与仅从文本推断的情绪；只有字幕不能称听审。声源/说话者、音量/节奏/停顿、情绪转折与环境音转成导演可用的节拍信息，导演负责最终摄影，不重复两份完整提示词。

## 配乐双框

先按本场设计Quiet/Build/Peak/Collapse/Silence/Resolution或Hook的必要节点，不强制走全六段。用实际乐器、音区、奏法、密度、节奏/有依据BPM、停拍与过渡表达状态。音色随状态而非永久绑定角色；有意重复动机不等于失败。

交中文简要动态弧线、英文Style框、英文Structure框及有依据的声画节点。声学/近拾音/少层是公司可选预设，电子需求按任务处理，不套禁合成器；mf/f是作曲意图不是LUFS。Style/Lyrics界面不是所有服务通用，按当前入口适配，命令不保证精确时码。

重要对白/笑点/拟音收薄或停音乐，音乐静默不删除全轨对白/呼吸/动作。高潮后有后果就留余量。已有无BGM锁保持，除非本次明确解锁或要求单独音乐版本。只有实际音频才给精确实测卡点；现成曲目推荐核实曲名/作者/版本，未试听不伪造听感。

配音锁逐字文本、语言、发音/声音参考、自然语速与气口。音效写原因、材质、距离、空间和同步动作。实际输出须查时长/峰值/失真并听审；没有生成工具就交方案，不造文件链接。

快捷句：“按集原样提取台词。”“给这段剧情英文Style/Structure双框，重要对白处停音乐但保留拟音。”“根据这段音频写视觉节奏，听不到的别猜。”
