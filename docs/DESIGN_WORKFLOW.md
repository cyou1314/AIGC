# 专业视觉设计与学习工作流

适用海报/封面、人物/服饰/场景、UI/网页。新增3个Skill，共20个；保留9类生产profile与原R0–R8，不用平面排版替代角色设计或网页功能。

## 选择当前动作

| 当前需求 | 主Skill | 交付与验收 |
|---|---|---|
| 海报、封面、社媒排版 | canvas-design | 精确文案、层级/网格、合法字体；请求的源文件/导出与实际渲染 |
| 人物、服饰、场景设计 | aigc-image-director | 身份/世界观共享锚点；专项参考、真实图片或明确prompt-only交付 |
| UI网页设计 | frontend-design | 现有栈/token、核心路径与状态；宽窄屏、键盘和实际交互 |
| 设计诊断、验收、A/B学习 | aigc-design-review | 证据/位置→影响→修改→保护项→复验；未看输出不称视觉QC通过 |

图像主视觉→海报排版是可选交接；已有主图不再生成。网页需要人物图时另交接图像设计；普通UI任务不做角色设定。审稿请求本身不授权修改或付费重做。

## 专业细节

海报：主视觉与精确中文文字分层；源文件可编辑且资源可恢复。多比例重新编排，保留完整必要信息。印刷按印厂的实际bleed/profile要求核验，不把RGB截图当印刷通过。

人物：用途/身份/轮廓/比例/表情与多视图；服饰：内外层、开合、绑带、材质、重力和活动功能；场景：路径/尺度/透视/结构/光源和空间锚点。三者共享ID/版本与世界观，不默认同一种写实风格。图片不等于裁剪纸样、可建模三视图或可施工空间。

UI：内容/任务先于装饰；中文排版、token、状态、响应式、语义标签、焦点/键盘与reduced-motion。Figma是可选专项交付，不是本地网页的必装依赖；发布与账号连接按用户授权另验。

## 学习循环

设计brief→参考职责→代表小样→实际检查→一个最高影响变量的修正→同条件比较→项目经验候选。记录原/改版、观察、修改理由、适用条件、反例与未知成本。仅在实际复现/用户明确规则或跨项目证据后讨论晋级，不把安装、阅读或一张好图当永久能力升级。

学习记录模板位于 `aigc-design-review/references/review-learning.md`。`review_gate.py`只能验证证据记录格式和严重度闸门，不能自动判断美感、身份或交互真实性。

## 来源与升级

canvas-design/frontend-design各有SOURCE.json、LICENSE.txt与原文快照。固定上游版本用于追溯；更新时先安装到临时目录，比较新旧上游与本地适配，再做三方审阅，不用新上游入口直接覆盖中文/平台规则。字体不自动下载或打包。

旧图像导演实有20份参考；本轮恢复6份方法全文并添加3份专项规范。见 [迁移索引](../skills/aigc-image-director/references/recovery-index.md)；没有宣称其余14份或旧51KB入口完整迁移。

局部升级支持：

```bash
python scripts/manage.py upgrade --skill canvas-design --skill frontend-design --skill aigc-design-review --skill aigc-image-director --skill aigc-production-router --skills-only
```

生产Skill有本地修改时仍停止；审阅并备份后才能使用现有显式adopt/replace选项。新Skill先纳入sources.json、结构检查、行为测试、同步register；注册保留旧基线。完成后正常同步，并用远端SHA确认。

## 验收任务

1. 精确中文文案海报：SVG/HTML可编辑，实际渲染检查文字/裁切。
2. 人物+服饰+场景：prompt-only设计合同检查身份/层次/空间/参考角色，不宣称生成了人物图。
3. UI设计：真实浏览器宽/窄屏、筛选/空状态/键盘和布局检查；没有后端或部署就不声称上线。

自动测试检查路由、证据闸门和安装保护；美术判断需要实际项目反馈。维护脚本为跨平台Python；此设备的macOS渲染不等于Windows原生测试。
