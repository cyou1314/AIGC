# 工具集成与能力检查

## 集成边界

仓库负责专业流程、配置和本地脚本；生成服务负责实际模型运行。插件安装、官方登录、API权限、点数、区域和模型可用性在新设备重新检查，不复制旧电脑的插件缓存或浏览器会话。

| 生产能力 | 可选集成示例 | 实际验收 |
|---|---|---|
| 图像/局部修改 | Codex imagegen、Cowart、Kling、Adobe | 取得实际图片，主体/文字/区域核验 |
| 叙事视频 | Kling或本轮明确指定的视频服务 | 成功任务、可读视频、时长与连续性 |
| 商业/主持内容 | Higgsfield对应UGC/AI host/faceless专家 | 商品真实性、身份、语音、真实成片 |
| 3D | Meshy；本地Blender预演 | GLB/FBX等目标文件导入，不只看预览 |
| 音频转录 | transcribe支持的合法服务；本地工具按需 | 实际文本与音频词句比对 |
| 配音/音乐/音效 | 当前会话可用的专用服务 | 真实音频、试听、时长、合法授权 |
| 工程后期 | 剪映/CapCut、CLI、FFmpeg；可选云剪辑 | 重开编辑工程/导出视频/试听 |
| 文档/演示/表格 | 对应文档工具、Google Drive/Docs/Sheets/Slides | 内容读回、渲染、公式/格式核验 |
| 网站/应用/Agent | Sites、已有仓库工具、指定SDK平台 | 核心用户路径；部署实际访问 |

以上是路由可接的能力类别，不是安装承诺或排名推荐；模型名、参数、费用与版本按当前官方说明/工具schema核验。没有目标能力就明确缺失，不用提示词冒充实际结果。

## 单工具接入验收表

```text
工具/插件：
本机是否可发现：
官方登录/权限是否确认：
当前任务类型与限制：
预算/计费授权：
输入文件及其参考职责：
最小样本任务ID：
实际输出文件：
验证方法与结论：
失败原因与唯一下一步：
```

只安装成功填写“可发现”；真正请求成功且取得文件才填“实际生成成功”。只有模型完成没有下载/可读结果，仍不能作为交付成功。

`scripts/doctor.py`是只读本地发现，不登录、不上传、不付费，只报告密钥是否配置的布尔值。它不验证服务权限、点数和模型可用性，也不是万能媒体检查。

## 安全与成本

不提交 `.env`、Cookie、CK、Token、密码、OAuth设备码、浏览器profile或带凭证URL。私有仓库仍不是密钥库。凭证由用户在官方服务/系统安全存储配置。

试运行先选一个小样并确认预算；批量生成、外发、公开部署或发布采用用户当前任务的授权边界。涉及真人声音/身份、品牌资产和第三方媒体时登记授权来源。

旧Antigravity路由保持暂停；未重新安装和实际验证前不调用旧 `agy` 命令，也不将消息开头的1/38识别成模型选择。
