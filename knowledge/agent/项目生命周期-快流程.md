# 项目生命周期：快流程

## 1. 登记

在 `projects/` 新建当前项目页，写明：

- 一句话目标与交付物
- 生产类型、完成条件与已知预算；未确定类型不默认漫剧
- 当前阶段
- 权威素材和版本
- 硬约束
- 输出目录
- 唯一下一步

普通任务用 [[_项目快速模板]]；多镜头、跨会话或多轮返修用 [[_项目模板]]。

## 2. 执行

1. 根据 [[agent/跨类型AIGC生产工作流]] 选择生产类型，叙事制作再按 [[01-快速路由]] 调用模块；已有项目延续其路由。
2. 一轮只解决一个主要问题。
3. 生成文件放在真实项目目录或 `{{AIGC_OUTPUT_ROOT}}`。
4. 真实结果出现后再写回执；状态只用 `候选 / 采用 / 成片 / 废弃`。

## 3. 验收

按实际交付类型检查：图像看身份/文字/裁切，音频需试听，3D需导入/用途核验，文档需来源/渲染或重算，应用需运行；视频生成工具的必要输出检查按工具要求执行。只有明确请求视频内容质量/口型/连续性/返修时按 [[成片验收与返修能力]] 做专业内容QC。用户确认成片可直接登记完成，不强制额外分析。

## 4. 收尾

- 更新权威版本、交付路径和唯一下一步。
- 未解决事项写入 [[TODO]]。
- 经验先写入项目页“知识候选”；跨项目验证后再晋级。
- 项目结束后只保留可恢复状态，不保留冗长过程流水。
