# 专业视觉设计工作流

主手册：AIGC仓库的 `docs/DESIGN_WORKFLOW.md`；执行规范按需读取已安装Skill，不复制每份审稿表。

| 需求 | 当前动作主导 |
|---|---|
| 海报/封面/中文排版 | canvas-design；主视觉需要时交图像导演 |
| 人物/服饰/场景/静帧/局部编辑 | aigc-image-director；三份专项规范共享身份与世界观 |
| UI/网页视觉与交互 | frontend-design；保留现有技术栈、组件与token |
| 明确审稿/验收/A-B学习 | aigc-design-review；不自动授权生成或修改 |

共用流程：用途/权威输入/保持项→参考职责→代表小样→实际检查→局部修改→同条件复验→项目经验候选。任务大小决定文档深度，不机械串联所有专家。

完成依据：海报检查精确文字/渲染/源文件；设定检查身份/层次/空间且概念图不算纸样/施工图；UI检查宽窄屏、状态和核心操作。缺实际输出只报告brief/source检查，不称视觉通过；缺部署不称已上线。

升级依据：新增canvas-design、frontend-design、aigc-design-review，恢复旧图像导演6份通用参考；20份历史资料不是全部已迁移。上游固定版本、许可证与适配原文见各SOURCE.json；图片、账号与私人项目不进GitHub。

维护：生产路径由本机配置确定。新Skill/通用知识先登记并测试，收尾在仓库用已验证解释器运行 `scripts/sync_github.py run`；只有远端main与本机HEAD一致才声明同步。
