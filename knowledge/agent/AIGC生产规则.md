# AIGC 生产规则

适用领域：AIGC视频制作 · 相关项目：项目地图 · 资产：资产索引

## 推荐顺序

1. 检查真实素材和项目当前版本；
2. 拆解剧情、歌词或音频，先确认内容边界；
3. 形成可审阅的分段和停止点；
4. 确认角色、场景、空间轴线、时长和画幅；
5. 写分镜与镜头级提示词；
6. 生成并记录真实输出路径；
7. 用户确认该输出是成片后，登记位置、结束项目并总结本项目对话；
8. 只有用户明确要求质量、口型、连续性、分镜符合度或返修分析时，才读取成片并执行QC；
9. 明确QC后只写返修差量，必要时才重写完整提示词；
10. 把最终状态和下一步写回项目页。

- 发现新的 AIGC 资产目录但尚无项目页时，只创建轻量登记：记录目录、已见资产类别、片型待确认、主导 Skill 和唯一下一步；不因资产数量大而全量阅读，也不把文件自动标记为生成、采用或成片。

## 提示词

- 使用真实裸 `@名称`，同时写明对应分镜格或素材用途。
- 新分支或独立镜头先写“继承什么、明确排除什么”；当前用户素材和当前镜头合同优先于父项目旧提示词。只引用会影响当前镜头的最小素材集，不能因处于同一项目就自动带入旧场景、旧对白、旧时长或旧连续性。
- 提示词保持中等密度，镜头、构图、调度、动作、光线和声音具体可执行。
- 对白以音频为权威来源；压缩片段时不能让可见对白异常加速。
- 角色设定图只锁定身份和外观，默认不继承白底、排版、多视图或文字。
- 新设定覆盖旧设定时，交付完整修订版，不能让用户自行拼接。
- 用户明确给出剧本行号、镜头范围或开场状态时，先清除范围外的旧动作、资产、场景和状态，再编译当前提示词；范围外内容不得因旧项目连续性自动带入。
- 外部周报和案例按 [[agent/AIGC周报吸收流程]] 做来源核验与候选筛选：只有能改变故事节拍、动作可读性、构图/运镜、表演/反应、声音/剪辑、连续性、模型稳定性或返修方式的内容才接入对应条件模块；其余丢弃。未经官方核验或真实生成/QC支持的平台参数、时长上限和效果保证不进入默认规则。

## 连续镜头

- 每段需有自然切点和明确动作接口。
- 继续下一段前，优先检查上一段实际尾帧，而不是只读文字描述。
- 继承：机位、构图、裁切、人物姿态、屏幕方向、空间轴线、光源、视线、动作惯性和情绪状态。
- 实际尾帧未取得时，明确标记“待尾帧”，不能声称连续性已锁定。

## 白模预演与导演验收

- Blender或其他白模预演通过相机连续、脚滑、穿地、碰撞、媒体编码等技术检查，只能证明方案可执行，不能证明动作语义、构图、遮挡和节奏已经复刻正确。
- 高成本整段动画前，先核对关键节拍的屏幕空间关系：人物画面侧、比例、运动方向、遮挡、桥接位置和镜头任务；关键静帧明显不一致时，不用技术报告掩盖导演问题。
- 复刻参考或搭建新场景时按层确认：静态场景尺寸与拓扑 → 人物位置和朝向 → 固定机位动作 → 运镜与剪辑。前一层未确认时，不继续投入后一层的高成本制作；这是一组按项目复杂度伸缩的验收门，不是要求所有项目机械走满四步。
- 只有用户导演明确接受的预演，才能作为后续生成的运动交接参考；被否决版本保留为失败证据，不标记为采用或成片。
- 依据：DaoYan-box 中 `320` 预演技术检查通过但被用户否决，后续据此改为先校准屏幕空间和单一连续动作。

## 互动剧

- 详细提示词前先提交剧情分段供确认，并明确停止位置。
- 不删除关键剧情来迎合预设时长；保留停顿、观察、环境声、动作惯性和悬念递进。
- 每个镜头必须推动剧情、情绪或威胁升级。

## 儿童歌曲视频

- 先按完整歌词含义分段，再设计内部镜头，避免同一段歌词跨段错位。
- 角色互动要有“发起者 → 接收者 → 回应”的完整链条。
- 互动链必须符合物种自然行为。优先使用视线回应、主动让路、动作模仿、自然同行和同一路径的不同运动方式；避免动物像人一样敲鼓、列队，或刻意操纵气泡、水花、露珠等媒介。
- 道具只作为动作媒介，不能抢走歌词主体。
- 每个单段提示词前写明时间、音频、结构、真实参考角色和段落意图，减少批量生成时的角色与歌词错配。
- 15秒儿童歌曲片段可先以4个内部镜头作为稳定起点，但必须按真实歌词节奏调整，不能机械平均切分。
- 时间戳没有音频或转录证据时，标记为估算，不能伪装成精确同步。

## 成片登记与可选质量分析

- 默认“验收这个成片”只登记文件位置，项目标记完成，并总结当前项目对话。
- 默认不播放、不抽帧、不转录、不解读视频内容，也不调用FFmpeg或QC Skill。
- 成片存在是项目完成证据，不自动代表已经分析画面或声音质量。
- 只有用户明确要求质量、口型、连续性、分镜符合度或返修分析时，才进入内容QC。
- 明确QC时再分开记录观察证据、可能原因和返修建议，并使用：通过 / 可修后通过 / 需要重做 / 证据不足。
