# 动作力度与物理反馈

> 把“更用力、冲击更强”等抽象词转换为可以被画面验证的因果链。

## 因果链

`发力源 → 接触点 → 动作路径 → 主体变化 → 环境反馈 → 归稳`

按镜头需要选择：

1. **发力源**：手指、手腕、肩背、重心或整个物体如何发力。
2. **接触点**：力量实际作用在哪里。
3. **动作路径**：方向、速度、持续时间和是否持续施压。
4. **主体变化**：位移、变形、下降、摩擦、破裂或停止。
5. **次级反馈**：邻近物体随动、尘土、水体、衣料和姿态变化。
6. **安全边界**：必须保持稳定、不破坏或不遮挡的元素。
7. **摄影反馈**：短促颤动、跟拍或归稳，幅度与冲击相称。

## 动作戏拆解

分镜时长跟着动作功能变化，不把30秒平均切成等长镜头。先写清每一招的链条：起始架势与攻击线 → 防守或闪避 → 接触点 → 反击 → 对手/环境反馈 → 双方归稳，再按动作快慢安排短插针、慢动作或停顿。

法术另写一条可复现的因果链：蓄势信号 → 身体发力 → 施法媒介和运动路径 → 对手如何格挡/躲避 → 命中结果 → 光效消退。能量方向必须跟手、兵器或身体动作一致；大招应分成蓄势、释放、推进、碰撞、余波，不用满屏光效代替招式本身。慢动作留给关键接触、蓄势或选择瞬间；全屏终招只安排在节奏峰值，之后留出看清结果和角色归稳的时间。

当前依据：用户对《雁回关》30秒宣传打戏 v0.1 的明确反馈；作为可复用工作原则，仍需在真实生成和返修中验证具体时长与模型表现。

## 例子

- 推动物体：掌根持续施压 → 物体摩擦前移 → 邻近小物轻微随动 → 手臂与身体归稳。
- 重击水面：武器持续下压 → 水面形成明确凹槽 → 浪墙和水雾沿受力方向扩散 → 镜头短震后稳定。

## 反例

- 只写“非常用力、电影级冲击”。
- 用持续摇镜、纯白爆闪或大量粒子代替物理结果。
- 不顾镜头类型套满所有反馈；克制表演和细小动作应降低幅度。
