# Skill 创建与知识回写流程

## 何时创建 Skill

同时满足以下条件再创建：

- 同一任务已经重复出现。
- 输入、步骤、输出和停止条件相对稳定。
- 普通知识页不足以保证执行一致性。
- 有真实案例可以验证行为。

一次性经验写入 `learning/`，不要急着做 Skill。

## 创建流程

1. 明确触发语、适用范围和不适用范围。
2. 定义输入、步骤、证据和停止条件。
3. 使用 `skill-creator` 创建或更新。
4. 做结构校验，再用一个真实任务验证。
5. 在 [[Skill与知识库对应表]] 登记其负责的能力和知识页。

## 回写规则

- 项目事实回项目页。
- 方法解释和案例回 `learning/`。
- 稳定操作流程回 `agent/`。
- Skill 只保留执行所需指令，避免复制整套知识库。
- 行为变化后同步更新 Skill 与对应知识页，并记录最近验证日期。
