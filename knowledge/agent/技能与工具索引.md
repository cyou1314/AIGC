# 技能与工具索引

> 按任务选择最短可用链路。Skill 负责方法，工具负责执行，实际文件负责证明结果。

| 任务 | 首选 Skill / 工具 | 输出或停止条件 |
|---|---|---|
| 不同类型或混合 AIGC 制作 | `aigc-production-router` | 按交付选择一个主流程，保留明确阻塞与本类型完成条件 |
| 图像导演、海报、角色、商品图 | `aigc-image-director` → 所选图像工具 | 参考职责、身份、文字、裁切和实际图像 |
| 广告、UGC、商品/社媒内容 | `aigc-commercial-content` → 对应专业生产 Skill | 卖点依据、商品真实、请求的渠道交付 |
| 独立配音、配乐、音效、播客 | `aigc-audio-production` → 可用音频工具 | 实际音频及实测/听觉证据；缺工具保留阻塞 |
| 剧本、剧情、对白 | `aigc-screenwriter` | 结构、场景或对白达到本轮目标 |
| 视频、分镜、运镜分析 | `ffmpeg` → `aigc-manga-video-director` | 有可核验的镜头分析或分镜表 |
| 图像生成与修改 | `imagegen` 或相应生成工具 | 真实图片文件产生 |
| 音频转写与声音提示 | `ffmpeg`、`transcribe`、`audio-to-prompt` | 有转写、声音分析或提示词 |
| 剪映草稿直接编辑 | `capcut-edit` + `capcut-cli` | 读取/检查/修改可编辑剪映时间线、字幕、节奏、音量、速度、转场和长转短；写入前保留备份并要求关闭剪映 |
| 非剪映通用口播粗剪 | `auto-edit-video` | 本地转写 → 保守删停顿/口头禅/重复 → 字幕/卡片/竖屏变体 → QA；缺 `ffprobe` 或本地 Whisper 时标记 `blocked-runtime` |
| 提示词修订 | `prompt-optimizer` | 冲突消除，目标和约束清楚 |
| 成片验收 | `aigc-output-qc` | 有实际成片和明确验收请求 |
| 项目与知识闭环 | `obsidian-codex-knowledge-loop` | 项目状态与知识候选已回写 |
| 新建或修改 Skill | `skill-creator` | 结构校验和真实行为验证通过 |

## 选择规则

1. 先判断交付物，再选 Skill。
2. 能用现成 Skill 完成时不新建重复流程。
3. 缺少运行条件时标记 `blocked-runtime`，说明缺什么；不伪造结果。
4. 只有真实生成和验收证据才能把经验晋级为稳定流程。
