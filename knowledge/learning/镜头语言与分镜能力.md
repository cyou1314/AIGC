# 镜头语言与分镜能力

> 目标：把剧情信息拆成时长可行、空间清楚、能够连续生成的镜头。

## 分镜最小单位

每个镜头至少写清：

- **目的**：交代、强调、反转、过渡或释放情绪。
- **起点**：人物、道具、视线和摄影机的初始状态。
- **变化**：镜头内唯一主要动作或信息变化。
- **终点**：下一镜可以承接的画面状态。
- **时长**：动作和信息是否有足够时间被看清。

## 镜头选择

| 问题 | 优先选择 |
|---|---|
| 交代空间与关系 | 全景、固定或缓慢移动 |
| 强调人物反应 | 中近景、近景，减少背景干扰 |
| 揭示信息 | 推近、横移揭示、遮挡后显现 |
| 表现力量与压迫 | 低机位、快速逼近、明显环境反馈 |
| 表现失衡或危险 | 倾斜构图、受控手持、突然变速 |

## 连续性检查

- 轴线、运动方向、人物视线一致。
- 上一镜结束姿势能成为下一镜开始姿势。
- 景别变化有动机，避免无意义跳切。
- 道具位置、服装、时间与光线可衔接。
- 镜头越复杂，持续时间越长；短镜头只保留一个主要变化。

## 分析纪律

- **观察事实**：画面中能直接看到或听到的内容。
- **专业判断**：对景别、运动、节奏和作用的解释。
- **待确认项**：素材不足时明确标记，不补写不存在的信息。

## 输出模板

`镜号｜时长｜镜头目的｜景别/机位｜主体动作｜摄影机运动｜声音｜起止状态｜连续性要求`
