# AIGC 项目统筹与提示词能力

> 目标：让每轮工作只有一个权威状态、一个清楚目标和一个可验证的下一步。

## 项目控制六项

1. 当前目标。
2. 当前阶段。
3. 权威输入和版本。
4. 必须遵守的约束。
5. 实际输出位置与状态。
6. 唯一下一步。

## 提示词结构

`目标结果 + 主体与环境 + 起始状态 + 核心变化 + 摄影机 + 光线/风格 + 连续性约束 + 禁止项 + 输出规格`

提示词只包含会改变结果的内容。冲突约束先解决；不确定内容标记待确认。复杂镜头优先拆分，不依赖堆词解决时长和动作冲突。

## 版本与证据

| 状态 | 含义 |
|---|---|
| 草案 | 尚未确认的脚本、分镜或提示词 |
| 候选 | 已生成真实文件，待比较或验收 |
| 采用 | 已被选中，可进入下游 |
| 成片 | 已交付或用户确认完成 |
| 废弃 | 保留原因，不再继续迭代 |

提示词完成不等于已生成；文件存在不等于已验收；项目页中的路径必须能够核验。

## 快速收尾

- 更新当前阶段、权威版本和唯一下一步。
- 登记真实输出及状态。
- 记录一个有效做法或失败原因；只在可跨项目复用时晋级知识页。
- 未解决事项写入 [[TODO]]。
