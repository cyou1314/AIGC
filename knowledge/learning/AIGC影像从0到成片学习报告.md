# AIGC影像从0到成片

## 成品

[新手知识报告与八周实战课程](https://docs.google.com/document/d/19xagtO8LqWaub-ADsoL9h5y2yawwKhD4fCRYRiLw4CA/edit)

报告将 Drive 中的剧本/分镜、人设交付、首尾帧、场景空间锚点、模型能力边界、导演质检与返修资料整合为 18 章新人教材，覆盖故事与脚本、人设/场景图、关键帧、视频生成、声音、剪映、QC、发布责任、八周练习与毕业示例。

## 可复用生产原则

- 按 R0 至 R8 推进：项目 Brief → 剧本 → 视觉资产 → 分镜镜头卡 → 关键帧 → 视频 → 声音 → 剪辑 → QC 与归档。
- 一镜一个主动作；全局设定写入角色/场景/风格 Bible，每镜只写本镜头差异。
- 首帧确定主体、空间与动作起点；尾帧确定结果和接镜点。生成结果必须逐镜头对照镜头卡验收。
- 生成记录、采用结果和 QC 结论属于不同证据。结论使用“通过、可修后通过、需要重做、证据不足”。
- 返修先定位到剧本、设定、分镜、生成、剪辑或证据层；一次改变少量变量并保留版本。

## 模型候选与使用规则

报告核对的候选包括：文字/多模态助手 ChatGPT、Gemini、Claude；图片 Seedream 5.0 Pro、Midjourney/Niji、Imagen 4、ChatGPT Images 2.0；视频 Seedance 2.5、Kling VIDEO 3.0、Veo 3.1；音频 Seed Audio、ElevenLabs；后期剪映/CapCut。

这只是按任务能力建立的候选名单，不是独立质量排名。供应商功能介绍、账号可用能力和真实镜头表现要分别核实。比较视频模型时用同一组参考图与提示词测试人物走路、手部拿道具、正反打对白，记录连续性、动作、可剪辑性、成本、授权及失败重试数。下单或商用前复核版本、地区、价格、隐私与授权规则。

## 新手提示词附录

2026-09-25 已在 Google Docs 报告追加可复制练习模板，覆盖角色 Bible、标准人设参考图、角色三视图、场景设定图、场景关键帧与首尾帧、I2V/T2V、剧本拆镜、剪映粗剪决策、QC 和单变量返修。案例沿用“夜雨便利店”，字段可替换为自己的项目设定。

角色图的流程原则：最新生成图先作为候选，经过人工检查并明确采用后才升级为当前标准参考图；跨镜头沿用已采用的标准图，避免未检查的偏差逐轮累积。附录提示词是教学模板，尚未对各模型逐一实测，也不代表实际生成或质检已完成。
