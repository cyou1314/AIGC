## 核心能力

1. 明确角色目标、为什么现在行动、阻碍、选择、结果和代价。
2. 把剧情拆成可视化 scene beat，而不是直接堆镜头。
3. 维持因果、空间、人物状态、威胁升级和下一场钩子。
4. 把对白转成可见动作、反应、停顿、潜台词和情绪转折。
5. 控制剧情边界：先让用户确认分段，再展开详细镜头。

## 剧情检查链

角色目标 → 当下动机 → 空间起点 → 阻碍 → 行动 → 结果 → 状态变化 → 威胁升级 → 下一场钩子。

## 训练顺序

### L1：理解

- 从现有短剧中提取角色目标、障碍、转折和结尾钩子。
- 把一页剧本拆成 scene beat，不写运镜。

### L2：可执行

- 将每个 beat 转成“建立关系 → 压力来源 → 人物反应 → 线索/变化 → 视觉钩子”。
- 保留停顿、观察、环境声和动作惯性，避免只追求快节奏。

### L3：可独立交付

- 完成一段可直接进入分镜的剧情拆解。
- 通过导演审核，剧情因果、空间和人物状态没有断裂。

### L4：可诊断优化

- 能判断问题来自剧情因果、节奏、信息顺序、人物动机还是镜头表达。
- 能在不删关键剧情的前提下调整时长和分段。
