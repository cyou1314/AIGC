# 职业技能练习与证据

从 [[learning/职业技能成长地图]] 选一条能力线；一次只练一个可观察的问题。Skill 是执行参考，学习页记录原理和边界，真实项目页保存当次事实。本页不把“读过 Skill”记作“掌握”。

## 可执行能力线

| 能力 | 本机 Skill | 学什么 | 一次最小练习 | 合格证据 |
|---|---|---|---|---|
| 编剧与剧情拆解 | `aigc-screenwriter` | 目标、阻碍、选择、结果、信息顺序、对白功能 | 选一场现有戏，写 5 个剧情节拍并指出一处因果缺口；只诊断，不擅自改写 | 带原文依据的诊断和修复方向；需要改写时另留采用版本 |
| 导演与调度 | `aigc-manga-video-director` | 镜头目的、人物调度、情绪节奏、动作因果、跨镜接口 | 对一段 20–30 秒素材，逐镜写“画面事实 → 叙事作用 → 可执行调度” | 分镜/镜头表、参考帧与时间码；推断单独标记 |
| 镜头语言与分镜 | `aigc-manga-video-director` 的镜头分析模块 | 景别、机位、构图、物理运镜、变焦、主体运动和剪辑 | 取 5 个连续镜头，写起始构图、运动证据、结束构图和下一镜头方向 | 真实帧或视频时间段支持判断；不能从单帧声称连续运镜 |
| 声音与表演 | `audio-to-prompt`、`transcribe` | 真实台词、停顿、呼吸、重音、动作反应和口型时序 | 用一段真实音频做时间卡，标出说话、停顿和可见反应节点 | 音频来源、时间段与画面设计；无音频时只标“估计” |
| 成片验收与返修 | `aigc-output-qc` | 对照镜头合同判断偏离、保留成功部分、选择最低成本修复 | 在明确需要 QC 且有真实成片时，检查一个镜头的起点、动作、声音和尾帧 | 真实视频、对照材料、时间段、结论与单一主要返修变量 |

详见 [[learning/编剧与剧情拆解能力]]、[[learning/AIGC导演能力]]、[[learning/镜头语言与分镜能力]]、[[learning/声音情绪与表演能力]]、[[learning/成片验收与返修能力]]。图像方向可按需进入 [[learning/图像导演与视觉设计能力]]；其独立导演 Skill 当前未在本机安装，不把历史归档当作已激活能力。

## 一次练习的记录卡

在真实项目页“知识候选”或独立练习笔记中填写；不要为了每次阅读创建新页面。

```markdown
### 日期｜能力｜练习材料
- 目标：本次只训练哪一个判断？
- 来源：原剧本/音频/视频/图片的可核验路径或链接与版本
- 观察事实：带行号、镜号或时间段
- 我的判断：为什么这样处理；不确定处标“推测”
- 产物：剧情节拍/镜头表/音频卡/QC记录的路径
- 对照结果：用户确认、真实生成或验收证据；没有就写“未验证”
- 失败点与下一次只改的一项：
- 能力等级：L0/L1/L2/L3/L4；升级依据：
```

## 练习节奏与升级门槛

1. 先用旧项目或公开片段做一项 20–40 分钟的诊断；不为练习自动生成媒体或消耗额度。
2. 在下一个真实项目中使用一次，并只把当前项目的事实写入对应项目页。
3. 对照用户确认或真实结果复盘。文本合理、文件存在、结果生成、成片 QC 是不同证据。
4. 同类问题在多个项目中稳定解决后，提炼到对应 `learning/` 页；改变执行流程且经过验证时才考虑更新 Skill。

能力等级定义见 [[learning/职业技能成长地图]]。没有真实项目或成片证据时，可记录理解和文本练习，不自动升为独立交付或诊断优化。
