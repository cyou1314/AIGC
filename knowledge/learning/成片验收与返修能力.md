# 成片验收与返修能力

> 只有实际图片、视频或音频可以作为验收证据。

## 验收顺序

1. **可用性**：文件可打开，时长、尺寸、声音和尾帧正常。
2. **叙事**：镜头目的是否成立，信息是否看得懂。
3. **连续性**：人物、空间、动作、道具、光线和声音是否衔接。
4. **表现**：构图、动作力度、表演、节奏和情绪是否达到目标。
5. **瑕疵**：闪烁、变形、穿帮、口型、字幕和技术问题。

## 结论

- **通过**：可直接进入下游或交付。
- **有条件通过**：问题明确且不影响主要目标，可在剪辑或局部修复。
- **返修**：主要目标未成立，但保留部分仍有价值。
- **重做**：基础设定、动作结构或连续性无法局部修复。

## 返修原则

1. 先写“现象”，再判断原因。
2. 找到一个主要矛盾，选择最小修复层：剪辑 → 局部重生成 → 单镜重做 → 结构重做。
3. 保留已经有效的人物、构图、动作段或声音。
4. 修改后只复验受影响项目及其上下游连续性。

## 返修记录

`文件/镜号｜现象｜证据时间点｜原因判断｜修改动作｜复验结果｜最终状态`
