# 服饰设计与制作边界

区分时装视觉、角色服饰、商品试穿、结构设定与真实裁剪制作。商品试穿必须保持真实商品细节；裁剪纸样需要尺寸、面料和制版工具，概念图片不证明可制作。

设计合同：时代/世界观、职业与活动、气候、人物身份、廓形、层次、面料和功能。历史准确性有要求时核验专门来源，不编造年代服制。奇幻设计可重组形态，但开合、支撑和活动逻辑仍需自洽。

从里到外标注内层/外层/护具/附件；指明穿脱路径、接缝、系带/扣件和重量承载。长袖与武器/工具不互相穿模，披风/裙摆随材质与重力变化；皮革、金属、纱与粗织布不能只换纹理却保留同一垂坠。

选择一个主轮廓和受控的材质对比。细节集中在需要表达职业、等级或功能的部位，不让所有边缘堆满装饰。正背/侧视图保持同一领口、开合位置、腰带、左右附件和层次。

换装合同：CHANGE ONLY服装指定层；KEEP人物脸、发型、体型、姿态、相机和背景；LOCAL MATCH保护曝光、光线、接触阴影。缺背面参考时标为新设计提案，不称“原样还原”。

交付服饰ID/版本、层次/材质表、保持项、允许变体和实际图；需要制作的测量、纸样、工艺和试穿验收另列未完成。
