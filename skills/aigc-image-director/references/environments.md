# 场景概念与空间系统

先明确场景用于海报背景、电影静帧、连续镜头、游戏关卡、建模或真实空间设计。概念图不是可施工图，预览不是可导航关卡。

从使用目的建立空间：主体/事件、入口出口、关键通路、可活动范围、建筑/地形锚点与尺度参照。门窗、楼梯、台阶、支撑和道具占位应服务功能，不只是填满背景。

先大形与明暗，再透视、尺度、光源和局部材料。前中后景各有任务，路径应通向实际目的地；明暗和边缘层级保护叙事焦点。风格可以摄影、绘画、动画、水墨或图形化，不因“电影感”自动压暗、加雾或强制21:9。

连续视角锁定平面关系、地标、光源、材质和时间状态；反打/反向视角重新推导位置与朝向，而非直接镜像。不能从单张图片断言未见区域的真实几何。

世界观通过磨损、使用痕迹、修补和材料表达；每个细节有因，不堆无职责粒子。人物尺度参照和通路可读性先于微纹理。需要建模时给参考视角、尺寸假设和结构疑点；需要真实空间则另走专业测量与工程审核。

交付场景ID/版本、空间锚点、视角/比例、光色/材质规则、实际参考和未解决视角。局部编辑锁定相机、水平线、尺度与光线；不把重建画面当原图局修。
