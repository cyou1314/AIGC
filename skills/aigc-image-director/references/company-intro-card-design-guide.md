# 设计参考：剧情先于风格

这是可选的视觉语汇，不是“题材→固定颜色”的映射表。先读角色在目标集中的行动与关系，再选择适合该作品的组合。

## 选择依据

- **情绪与观看距离：** 轻松亲近、温柔克制、荒诞活泼、危险压迫、神秘疏离等，会影响字体亲和度、线条张力、材质与装饰密度。
- **时代与世界：** 当代校园、复古都市、历史宫廷、架空幻想等，有不同的字体、图形与物件语言。不能无依据加入异文化宗教徽记、王冠或军衔标志。
- **角色差异：** 同一体系内，用已经出现的物件、行动和关系区分人物。颜色只是辅助，避免只用粉色/蓝色表示性别、只用红色/黑色表示善恶。
- **实际叠加：** 以小尺寸短时间可读为先。浓重背景、复杂饰带或密集纹样会挡住视频，应把风格放在图标、字形、线条和局部装饰上。

## 可组合的视觉方向

| 视觉语汇 | 可采用的具体表现 | 使用时需要判断 |
|---|---|---|
| 粉彩可爱、贴纸手绘 | 桃粉、奶油白、浅杏等局部色；软圆字形；手绘物件；轻盈小装饰 | 适合轻松甜蜜或角色可爱感，不把现实受虐与严肃悲剧随意卡通化 |
| 清爽校园、生活插画 | 清透薄荷、天蓝或珊瑚色线条；练习本式细线；小文具或兴趣物件 | 依据真实校园/日常情境，不默认加校徽、学科或职业 |
| 复古浪漫、柔和印刷 | 温柔衬线体；低饱和樱桃、奶油、旧纸色的图形元素；轻微印刷感 | 纸感只在实体图形上，卡内外空白仍透明；不额外铺旧纸底 |
| 冷静悬疑、极简线描 | 细窄字体配清晰正文；银灰、冷白与少量强调色；留白和有张力的局部线条 | 神秘感来自已知剧情，不用隐藏身份图标提前给出谜底 |
| 黑色电影、克制奢华 | 高反差字形；精致物件；可选金属、珐琅或刻线；低密度装饰 | 金属只是选项，作品可以选择纯线描；不把“黑帮”自动画成游戏徽章 |
| 轻喜剧、扁平漫画 | 明快局部色块；活泼但可读的字形；夸张物件和节奏感轮廓 | 保持人物有尊严；色块属于图标/字形，不做遮挡画面的大底板 |
| 古典宫廷、细笔装饰 | 适合设定的纹样、印章、花枝或器物；衬线/书写体标题加清晰简介 | 不把普通人物擅自加冕；匿名人物也不编家族与官职 |
| 幻想童话、柔软微光 | 手绘星点、植物曲线、已建立的魔法物件；轻柔渐变限定在图形内部 | 不能凭空赋予角色魔法或阵营；光晕贴近元素，不能填满透明区 |

同一部作品可以融合两种视觉语汇，但应先确定共同的字体、布局和图标画法，再用人物局部差异变化。

## 完整提示词的表达骨架

下面是待按剧本填写的模板，不是已经判断好的角色事实：

```text
设计一张用于视频叠加的横版人物出场介绍卡，画幅约4:1。[该作品确定的整体风格]。[共同构图、轮廓、材质、字体层级和留白]。左侧设计[从当集角色信息提炼的专属图标与细节]，使用[本人物在共同体系中的局部色彩]。右侧上行以[大字设计]准确写“[原文姓名或当时称谓]”；下行以[清晰小字设计]准确写“[目标语言的一句简短介绍]”。[长姓名或其他本卡必要适配]。真实透明PNG素材：框内、框外和文字间隙的所有空白均透明，只保留图标、文字及必要边框装饰；图标本身可以有材质和颜色，不生成整块底板、玻璃实底、雾状底色或棋盘格图案。局部阴影或光晕紧贴元素，边缘完整、文字清晰，只显示指定卡内文字。
```

## 两种不同风格的虚构示例

以下姓名和剧情仅为教学示例。实际使用必须替换为用户剧本中的证据，不沿用这些设定。

### 清甜手绘例

示例前提：用户指定第2集。一名叫林栀的美术生在该集第一次出场，给同学画了一张小贺卡；整部作品是轻松、明亮的校园恋爱故事。

```text
设计一张校园恋爱短剧使用的横版人物出场介绍卡，画幅4:1，柔和粉彩手绘贴纸风，保持轻松明亮的生活气息。采用细腻的桃粉与奶油白线条，软圆轮廓，轻盈留白，整套人物卡统一使用圆润标题字与清晰的细体简介。左侧画一张折起一角的小贺卡，卡面点缀一朵手绘小花，旁边放一支短铅笔，画法简洁可爱。右侧上行以清晰的大字准确写“林栀”；下行以小一档的深玫瑰灰文字准确写“把心意藏进画里的美术生”。真实透明PNG：边框内外与字间的所有空白透明，只保留文字、手绘图标和细线装饰；色彩局限在图形与字形本身，不铺粉色底板，不生成纸张实底或棋盘格背景。完整保留边缘，简介一行可读，仅显示这两行文字。
```

### 克制悬疑例

示例前提：用户指定第5集。陆闻以失物保管员身份出场，动作是登记一把陌生钥匙；后文有未公开的身份反转。这里只用第5集公开的信息，不用后文真相。

```text
设计一张当代悬疑短剧使用的横版人物出场介绍卡，画幅4:1，冷静克制的极简线描风。采用清晰冷白字与灰蓝细线，狭长圆角外轮廓，充足空白；整套人物卡统一使用窄体无衬线姓名与易读的常规简介。左侧设计一把普通钥匙穿过登记卡纸角的细线图标，物件朴素，细节集中在钥匙齿形与一条尚未写满的登记横线。右侧上行大字准确写“陆闻”；下行小字准确写“替陌生人保管遗失物的人”。材质保持平面线条，不使用金属浮雕或豪华纹章。真实透明PNG：框内、框外与字间空白全部透明，只保留姓名、简介、图标和细边框，不生成灰蓝背景板、雾状玻璃或棋盘格。局部反差适合叠加视频，所有文字与边框完整，仅显示指定两行文字。
```
