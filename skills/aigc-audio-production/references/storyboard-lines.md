# 公司分镜台词检查与提取

适用于 storyboard-lines-extract、分镜XLSX/TXT/粘贴文本按集整理配音台词；由 aigc-audio-production 承接。不是语音识别、翻译、语法修复或对白创作。两份上传ZIP字节完全一致，只整合一次。Python 3.10+，TXT使用标准库，XLSX可选依赖openpyxl。

## 原文与范围

优先真实对应台词列，识别章节/集数、分镜号、来源工作表/行/单元格内行和顺序。合并章节空白向下承接；无法确定章节时不猜。只有提示词列不把整格当台词，先定位实际对白范围。只处理选中集，不去重、不合并/拆句、不改顺序，不写回源表。

明确角色前缀可剥离，不确定冒号前文字保留。TXT默认每行全是台词，只有确认标签时用--strip-speakers。没有集数归一组，不虚构集号。实际语言可为en/pt-BR/es-MX；未知时仍可原样提取，不为数词转换猜语言，不翻译。

## 检查与应用分开

读取 [公司导出规则](dialogue-cleanup-rules.md)。标点清理、等值数字语言化分别提建议，不改大小写、人名、词语、重音、语法、拼写、语序或情绪。西语倒问号删除、横线/省略号清理是公司导出约定，不是通用语言纠错；上下文涉及打断、复合词、负号、日期、电话、范围等时保留语义并展示差异。

检查阶段展示“文件｜集数｜台词条数｜标点建议｜数字相关”统计表，并展示真正待确认项的原文→建议具体差异；不只展示计数就称已取得确认，不生成未确认的修正版。标点和数字分开授权，仅应用实际展示并获准的项；本次明确授权与展示项一致时直接执行，不重复询问。用户要原样或没有待修改项时直接原样整理，无需为可逆提取增加确认。

确认只对当前来源、版本、语言、范围及建议有效。日期/时间/小数/千分位/百分比/编号/前导零/大整数/未知数字读法不套普通整数规则；金额、牌面和骰子语境分别判断，不补货币。遇到脚本不支持的表达保持原文，单独提人工建议，不改JSON建议绕过校验。

每处最终变化须对应已授权建议，条数、集数、归属和顺序不变。确认只授权台词副本修改，不授权新剧情或外部发布。

## 交付与脚本

每集一个标题和一个纯文本代码块，正文每条一行，不夹角色名、分镜号、标记或解释；没有集数就一组。保留完整结果和原文副本，来源对照留在内部文件。

从本Skill目录使用：
- python scripts/storyboard_lines/build_lines_doc.py 输入.xlsx --mode check --language en --episodes 1-5 --output 检查.json
- 展示差异后，复制JSON为确认清单，只设置已授权条目的approve_punctuation / approve_numbers，不改来源、原文或建议。
- python scripts/storyboard_lines/build_lines_doc.py 输入.xlsx --mode extract --language en --episodes 1-5 --review 确认.json --confirmed --output 台词.xml

脚本同时输出TXT；XML是本地结构化文档草稿，不是已发布的飞书文档。--confirmed记录真实授权或无修改原样提取的条件，不能替代用户授权。原样提取时保持两个approve开关关闭。TXT不支持直接按集过滤，有集标题先按明确集数分组。

脚本拒绝来源/建议变更、无确认提取、超覆盖数字批准和覆盖输入路径。运行前仍确认输出是新的工作文件；脚本不能自动判断语言/确认意图或所有复杂数字。XLSX的公式型台词可能没有缓存值，遇到空值先核实，不称已完整提取。

默认交聊天可复制结果或本地文件。没有本次明确外部写入要求，不自动创建/更新飞书或其他在线文档；需要时再检查实际连接和目标，并回读核对。不可用就如实交本地结果，不宣称发布。

## 验收

对账源摘要、集数、条数、顺序、重复保留、逐条差异和原文件未改。随包桌面软件测试是作者历史声明；本次只报告在当前环境真实运行过的移植回归，不冒称已验证其桌面软件或飞书操作。
