# 公司台词导出约定与适用边界

依据 2026-10-10 读取的剧本检查桌面版 `src/shared/dialogueExtraction.ts` 中 `stripOuterSubtitleQuotes`、`cleanDialogueText`、`convertDialogueNumbers`、`numberToWords` 和 `pluralCardNumber`，以及 `src/server/dialogueCorrectionPolicy.ts` 的文字保护原则整理。源码与台词保护相关的 24 项测试当日通过。以上是附件作者的来源与历史测试记录，本次不冒称已访问桌面源码。随包 Python 实现不依赖其本机软件目录；当前结果以本仓库回归为准。删除西语倒问号、改横线/省略号等是公司特定导出建议，并非通用语言规范，只有本次明确授权后才应用。

## 标点：保留正文，只清理符号

- 去掉包住整行的 `"…"`、`“…”`、`「…」`，外侧有句末标点时保留合理的一枚。例如 `「Wait」!` → `Wait!`、`“Wait.”` → `Wait.`。只去外层，句内引用保留；`He said 「Wait」.` → `He said "Wait".`。
- 中文逗号、句号、问号、感叹号、冒号、分号、括号等统一半角；弯引号转直引号。英文缩写与所有格中的撇号保留，例如 `can't`、`I'm`、`Ethan's`。
- `…` / `……` 转成 `...`，保留有意义的句内犹豫与停顿；`,...` → `,`，`...?` → `?`，`...!` → `!`。
- 连续结束符中有问号时统一 `?`，其余连续感叹号统一 `!`：`?!` / `!?` / `??` → `?`；`!!` → `!`。
- 删除西语倒问号 `¿`、倒感叹号 `¡`，保留正常句末问号/感叹号。
- 文字间横线 `- – — －` 改空格；数字间横线按软件规则建议改为英文逗号。**区间、日期、电话号码、负号等存在语义时先确认，不当普通横线处理。**
- 处理横线与省略号的错误组合以及多余空格；`Mr.Blackwoodg` → `Mr. Blackwoodg`，不改姓名拼写、不拆成两条台词。
- 不删所有标点，不删除有意义的逗号、句号、问号、感叹号或句内引用。软件 AI 提示词中的句首省略号和大小写联动不直接移植；需要上下文判断的条目只提出建议。

## 数字：按实际语言和语境做等值替换

软件已覆盖英语、巴西葡语、墨西哥西语的非负整数（小于一百万）：

| 原文/语境 | 规则建议 |
| --- | --- |
| `I have 21 cards.`，英语 | `I have twenty one cards.` |
| `21`，葡语 | `vinte e um` |
| `21`，西语 | `veintiuno` |
| `Pair of 7s`，英语牌面 | `Pair of sevens` |
| `Par de 7`，葡语牌面 | `Par de setes` |
| `661`，明确骰子点数，英语 | `six, six, one` |
| `666`，明确骰子点数，西语 | `seis, seis, seis` |
| `$661`，英语金额 | `$six hundred and sixty one` |

金额语境优先于骰子语境。不要擅自补写原文没有的币种；软件规则保留 `$` 等原有符号。牌面数字的复数形式属于数字表达转换，不授权修改其他单词。

软件使用数字片段匹配，不能据此宣称已经正确支持小数、时间、日期、电话号码、编号、千分位、百分比、区间、大整数或所有语法性别/数的变化。随包脚本对常见复杂形式、前导零、字母数字混合编号和负数停止数字转换，并要求人工确认；仍需代理结合上下文复核。软件对 `661` / `666` 的骰子启发式不直接当作确认依据，随包脚本只有明确骰子语境时才逐位读；无语境时标为待确认。

## 台词内容保护

标点修改前后，应保留字母、重音字符、数字与词语顺序。允许与标点有关的空格及文字间横线清理，但不能借此拆词、合词或替换表达。数字转换单独核对数值、语言和用途，不能让普通标点安全校验把等值转换误判成改写，也不能通过数字转换放行其他文字修改。

始终保留大小写：`A BILLION DOLLAR LOSS?!` 仅改为 `A BILLION DOLLAR LOSS?`。`She go home.` 必须保持原句，不能改成 `She goes home.`。正文中即使有错误，也不得自行修正。
