# 漫剧画面特效决策

## 先确定职责

只在特效至少承担一种职责时使用：

- **信息**：回忆、幻觉、系统界面、能力状态或视角发生变化。
- **物理反馈**：击打、爆炸、速度、能量、环境天气或镜头震动。
- **情绪**：恐惧、眩晕、悲伤、浪漫、压迫或喜剧反应。
- **风格统一**：同一段落需要一致的漫画纹理、颗粒、黑白或边缘表现。

如果只能回答“画面有点空”或“看起来更酷”，先尝试构图、景别、镜头运动、停留时长和声音，不直接加特效。

## 强度与组合

- **L1**：轻微光晕、颗粒、暗角、环境雨雪、缓慢聚焦；用于维持氛围。
- **L2**：短促动感模糊、变焦推镜、冲击波、局部发光、漫画化；用于明确动作或情绪转折。
- **L3**：刀光剑影、强震闪、故障爆发、能力释放等；只用于高潮或关键钩子。

一个剧情落点选择一个主特效。震动、闪白、色差、模糊、字幕弹跳和冲击音全部叠满时，降低可读性并削弱后续高潮。

动作型效果应遵守受力顺序：预备、主体动作、命中、次级动力学、余波。衣摆、尘土、火花和环境反应通常不应与主体动作机械同步；具体滞后量由画风、动作速度和帧率在真实样片中校准。

## 常见误用

- 用特效掩盖动作方向、角色位置或镜头素材本身不清楚。
- 每个静态镜头都做同样推近，导致没有节奏层级。
- 环境特效跨镜头不连续，雨、雪、烟雾或光线突然消失。
- 强闪烁持续过久；对光敏观众不友好。
- 人物边缘、脸、字幕和关键道具被特效遮挡。
- 热门效果与世界观不一致，例如古风剧情随意使用数字故障。

## 执行与验证

应用前用 `capcut enums --scene-effects --jianying -H` 或 `--character-effects` 查询当前枚举；界面可见不代表 CLI 一定能稳定写入。先在草稿副本对单一镜头 dry-run 和实机预览。

验证顺序：关掉效果看叙事是否成立；打开后看职责是否更明确；暂停检查人物、字幕和道具是否被遮挡；连续播放检查前后风格和亮度是否跳变。未经过剪映视觉检查的效果不得标记为已学会。
