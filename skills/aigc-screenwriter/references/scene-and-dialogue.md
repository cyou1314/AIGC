# Scene And Dialogue

## Scene Card

Use only the fields needed:

```text
场次:
时间/地点:
进入状态:
人物目标:
压力来源:
关键行动与反应:
信息变化:
关系或权力变化:
转折:
离场状态:
下一场接口:
```

The exit state must differ meaningfully from the entry state.

## Scene Construction

- Enter as late as clarity allows and leave after the change lands.
- Give each active character an intention, even when the intention is concealment, delay, testing, or escape.
- Express pressure through choices and consequences, not only explanation.
- Preserve continuity of knowledge, injuries, props, promises, suspicion, and emotional residue.
- Do not insert camera language. Describe observable action only when it is narratively necessary.

## Dialogue Test

For important lines, know:

```text
说话人想得到什么:
为什么现在说:
表面意思:
潜台词:
对方反应:
说完后局面如何变化:
```

Revise or remove a line when:

- every character could say it unchanged
- it explains information both characters already know
- it repeats a visible action without adding intention
- it states emotion that action or resistance should reveal
- deleting it changes nothing

## Local Rewrite

When repairing one section:

1. Preserve confirmed upstream facts.
2. Identify the first broken beat or line.
3. Replace the smallest complete unit.
4. Remove dependent pauses, reactions, eyelines, or later lines tied to deleted dialogue.
5. Recheck the scene's exit state and next-scene interface.
