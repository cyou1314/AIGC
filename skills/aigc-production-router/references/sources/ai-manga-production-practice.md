# 二、seedance\-25\-prompt\-reviewer

## 2\.1 它能做什么

- 检查人物、服装、道具、参考标签是否前后一致

- 多时间段动作是否连续，有无重复、跳过或矛盾

- 画面左右、前中后景、人物朝向、视线、运动方向是否合理

- 说话者、可见脸、口型归属、越肩、反打、OS/VO 是否清楚

- 两条相邻分镜的位置、动作终态、道具持有、180° 轴线是否能交接

- 只在用户明确授权后修改指定画面，其他内容锁死不动

默认行为：你只说"检查"，它只报告问题，不擅自改写提示词。

## 2\.3 怎么使用

这个工具用于检查和修改已经写好的 Seedance 2\.5 分镜提示词。

最方便的使用方式，是直接把提示词发给它并说明“检查并修改”。它会一次完成：

- 找出人物、动作、道具、空间、口型等问题

- 判断哪些是明确冲突，哪些需要人工确认

- 在不改变剧情的前提下做最小修改

- 输出一份可以直接复制使用的完整提示词

- 列出具体改了什么、为什么改

- 说明哪些台词、人物、服装、时间和参考标签保持不变

如果只说“检查”，它默认只报告问题，不修改。
如果希望它直接修复，需要明确说“检查并修改”。

### 最推荐的调用方式

```text
这条提示词生成后出现了下面的问题，请根据问题检查并修改原提示词。

实际问题：
[例如：角色跟着灯光一起消失了]
[例如：没有说话的人也在动嘴]
[例如：人物坐到了桌子的另一边]
[例如：衣服没有按顺序脱下来]
[例如：上一镜头拿在右手的手机，下一镜头跑到了左手]

修改要求：
- 只解决我描述的问题
- 不改变剧情和台词
- 不改变人物、服装、道具、场景和时长
- 所有 @参考标签保持原样
- 检查修改后有没有残留旧状态或产生新矛盾

请输出：
1. 问题可能来自提示词的哪个描述
2. 修改后的完整提示词
3. 具体改动说明
4. 未修改内容说明

原提示词：
[粘贴完整提示词]
```

适合：已经生成过一次视频，能够明确说出成片哪里不对，希望针对性修复提示词。

如果没有上传或实际查看生成视频，工具只能依据你描述的问题修改，不能声称已经验证成片效果。

```text
重点检查：
```

```text
2. 修改后的完整下一条提示词

4. 哪些内容保持不变

```

适合：两个镜头单独看都没问题，但放在一起后人物跳位、动作重置或者道具换手。

```text

检查内容：
```

### 更简单的一句话用法

不想复制长模板时，也可以直接说：

```text
帮我检查并修改这条提示词，剧情、台词、人物、服装、道具、时间和 @参考标签都不要改。修改后给我完整提示词，并告诉我具体改了什么。
```

如果是相邻分镜，可以说：

```text
帮我检查这两条分镜能不能接上。上一条不动，只修改下一条有问题的画面。修改后给我完整的下一条提示词，并告诉我改了什么。
```

如果已经知道问题，可以说：

```text
生成结果里人物坐反了。帮我检查是哪段描述导致的，只修复这个问题，其他内容不动。给我完整修改稿和改动说明。
```

### 输出结果怎么看

工具完成“检查并修改”后，通常会给出：

- 检查结论：有没有明确冲突

- 问题列表：问题出现在哪里、为什么有问题

- 修改后的完整提示词：可以直接复制使用

- 修改说明：具体增加、删除或调整了哪些描述

- 保持不变的内容：确认没有误改剧情、台词、人物、服装、时间和参考标签

问题等级包括：

- 确定冲突：提示词内部存在明确矛盾，已经在授权范围内修复

- 需要人工判断：现有信息不足，不能擅自补写

- 建议优化：不是明确错误，但写清楚后更容易生成正确

- 未触发此检查器：当前内容不需要进行某项专项检查

提示词修改完成后，只代表文字内部的一致性已经检查。没有实际查看生成视频时，应以：
提示词内部一致性已检查；实际生成效果未验证为准。

## 小提醒

- 它只帮你查提示词文本前后一不一致，实际生成出来视频好不好还得自己看。

# 三、short\-drama\-poster\-director

## 3\.1 它能做什么

输入英文剧名、剧情概要、人物参考图，自动完成海报视觉决策（人物主次、站位、动作、构图、背景、色彩、光影、英文标题排版），输出一整段中文海报生成 Prompt。

产物是"海报生成提示词"，不是直接出图。拿到 Prompt 后再让豆包根据提示词\+人物参考图生成海报。

## 3\.2 安装

安装包：`short-drama-poster-director.zip`（不要解压）

[short\-drama\-poster\-director\.zip](图片和附件/short-drama-poster-director.zip)

安装步骤同 2\.2，上传后在"我的技能"看到 **海外短剧海报视觉决策系统** 即装妥。

## 3\.3 调用模板

```text
帮我做《英文剧名》的海报。
大概剧情是……（两三句话讲完）。
参考图在附件，图1是女主，图2是男主。
```

## 3\.4 拿到 Prompt 后继续出图

添加人物参考图，继续发：

> 请使用当前对话中的全部人物参考图，并严格按照上面的完整海报生成提示词生成一张 3:4 竖版海报。必须保持每个人物的身份和原有服装，不得换脸、串脸、换衣、增加人物或删除主要人物。英文标题必须准确写作：\[再次填写准确英文剧名\]。如果无法稳定生成准确英文文字，请保留干净、无遮挡的标题区域，不要生成乱码。
> 
> 

## 3\.5 出图验收清单

- **人物**：每张脸对应正确？有无换脸/串脸/多余人物？服装配饰是否与参考图一致？

- **构图**：一眼看出主角和核心冲突？人物有前后大小层级？不是"证件照排队"？

- **标题**：英文剧名逐字正确？避开眼嘴关键动作？无乱码/水印/平台 Logo？

- **光影**：所有人共享同一主光方向和色温？背景服务剧情不抢戏？

## 3\.6 常见问题

- **豆包输出多方案/长篇分析**：发"请严格执行输出约束，不展示分析过程，不给多方案，只保留【最终海报生成提示词】和一整段中文 Prompt。"

- **擅自换服装**：发"只修正人物身份与服装一致性。所有人物的服装、配饰、鞋履和穿戴方式必须严格保持各自参考图原样，不新增、不删减、不换色、不改款、不重新设计；其他已经正确的部分保持不变。"

- **没有人物参考图**：补一句"本次没有人物参考图。请完成剧情、构图、背景、色彩、光影和标题设计，但不要声称还原特定人物，也不要自行补写具体服装款式、颜色、材质或配饰。"

## 3\.7 3:4 海报扩展为 9:16（Outpainting）

做完 3:4 竖版海报后，需要 9:16 全屏版本时使用。严格锁定原图 100% 不变，只向上/下扩展画布（上方少扩 25%、下方多扩 75%），不重绘、不移动人物、不改标题。

**使用方式：**上传已完成的 3:4 海报，然后粘贴以下完整提示词发送。

```text
【3:4 海报扩展为 9:16 / 严格锁定原图 Outpainting】
这是一次严格的"画布扩展 / Outpainting"任务，不是重绘、重构、重排版、优化或重新生成海报。
输入图片是一张已经完成的 3:4 竖版海报。
最终目标：将原始 3:4 海报扩展为 9:16 竖版海报。
如果原图尺寸为 1536×2048，则最终画布尺寸约为 1536×2731。

【最高优先级：原始 3:4 海报必须完整锁定】
原始 3:4 图片区域必须作为一个完整、不可编辑、不可重新生成的锁定图层保留。
原始区域中的所有像素内容都必须保持不变。
绝对禁止修改以下任何内容：
- 人物身份、脸部、五官、发型、表情、视线、身体姿态、手部动作
- 人物大小、位置、比例、前后关系
- 服装、饰品、道具
- 原有背景、建筑、灯光、颜色、曝光、景深、特效
- 原有标题、标题文字内容、字体、字号、排版、位置
- Logo、任何已有文字或视觉元素

禁止为了适配 9:16 画面而移动、缩小、放大、裁切或重新排列原图中的人物和标题。
禁止对原始 3:4 区域进行 AI 重绘、局部重绘、修脸、补手、美化、锐化、风格化、重新打光或任何形式的二次生成。
原始 3:4 海报必须能够与输入图片像素级重合。

【9:16 画布扩展方式】
保持原始图片宽度完全不变，只增加画布的上下高度。不要向左右扩展。
原始 3:4 海报整体在最终 9:16 画布中略微偏上放置。

即：上方只进行少量扩图，下方进行主要扩图。
参考 1536×2048 原图：上方约新增 170px，下方约新增 510px，最终形成约 1536×2731 的 9:16 画布。
原始 3:4 海报区域必须完整保留在最终 9:16 画面内部，不允许任何裁切。

【新增区域生成规则】
只能生成原始图片以外的新区域。
新增区域必须根据原图最靠近边缘的背景内容进行自然延伸。
上方新增区域：延续原图顶部已有的天空、建筑、墙面、灯光、环境、雾气、纹理或其他背景元素。不得新增主要人物、标题或新的叙事主体。

所有新增内容必须服从原图已有的世界观、场景、建筑风格、色调、光源方向、光影关系、景深、透视、镜头焦段、颗粒、雾气、材质、电影质感。

【安全区原则】
原始 3:4 海报本身就是核心信息安全区。人物脸部、核心角色、剧名、重要动作和主要剧情信息全部继续保留在原始 3:4 区域内部。新增的上下区域主要作为 9:16 平台适配空间和背景延伸空间。不得因为新增区域而重新调整原海报的信息层级。最终即使再次按照原始 3:4 区域裁切，得到的画面也必须与最初输入的 3:4 海报保持完全一致。

【禁止】
禁止重绘原图。禁止重新构图。禁止移动/缩小/放大人物。禁止改变人物脸。禁止修改服装。禁止改变标题。禁止重新排版文字。禁止复制人物。禁止增加第二个相同人物。禁止新增无关角色。禁止左右扩图。禁止拉伸原图。禁止整体缩放原图来制造留白。禁止把3:4海报缩小后放进9:16背景。禁止生成边框/装饰框/海报套海报效果。禁止改变原图纵横比。

最终效果必须看起来像：摄影机原本拍摄的场景在上下拥有更多取景范围，而不是把原来的海报重新制作了一遍。
```

# 四、storyboard\-lines\-extract

## 4\.1 它能做什么

从分镜 Excel 或你直接粘贴的台词里，按集抽出**纯台词**，每集一个代码块，右上角一键整段复制。

它会顺手做两件事：**清掉多余的标点**（比如外层引号、弯引号、连续感叹号）、**把数字念成文字**（比如 `21` 变成 `twenty one`）。但**台词意思、语序、大小写、人名一个字都不会改**，也不会翻译、不会润色。

## 4\.2 怎么用（三步）

1. **发素材**：把分镜 \.xlsx 发上来，或者直接把台词粘贴进来，说一句"提取第 X\-Y 集"。

2. **看建议、点确认**：它会先列出一张对照表——**原台词是什么、建议改成什么、为什么改**。你回"全部确认"，或者说"第几条不要改"。**没确认的地方它一律不动。**

3. **拿结果**：每集一个代码块，直接整段复制走。

拿不准的数字（日期、电话、金额、编号、小数）它不会瞎改，会单独问你"这个怎么念"。

## 4\.3 它会动什么 / 不会动什么

### ✅ 会动（你确认后才改）

- 包住整句的外层引号、书名号

- 弯引号变直引号（“…” → "…"）

- 省略号 …… 变 \.\.\.

- 连续感叹号 / 问号合并成一个（？！？ → ？，！！ → ！）

- 西语倒问号 ¿、倒感叹号 ¡ 删掉

- 文字中间的破折号变空格

- 数字换成念法：`21` → `twenty one`；牌面 `7s` → `sevens`；骰子 `661` → `six, six, one`

### 🚫 绝不会动

- 台词意思、语序、情绪

- 大小写（大写就是大写，不替你改小写）

- 人名、词语、重音符号

- 语法错误（`She go home.` 不会替你改成 `goes`）

- 翻译、润色、补词、删词

- 句内正常的逗号、句号、问号和引用

# 六、storyboard\-prompt\-trimmer

针对 **Seedance 2\.0 Mini** 解析出来的分镜表做**提示词批量精简**：把每条分镜提示词里的「视觉锚点：…」「站位：…」「环境状态：…」「布光方案：…」等固定说明段整段删掉，其余文字、台词、画面、@标签、时长一字不动。

## 6\.1 它能做什么

- 分镜表（xlsx）丢进来，自动定位提示词列，按段标签整段删除指定说明块

- 默认删四段：视觉锚点、站位、环境状态、布光方案，也支持自定义段标签

- 只删目标段，其余逐字保留：台词、画面、@资产标签、时长、其他列全部不动

- 实写前自动 dry\-run 预检 \+ 自动备份，交付带校验报告，ok=true 才算通过

- 不负责改写剧情、重写镜头或创作新提示词

适用场景：Seedance 2\.0 Mini 解析分镜表后，每条提示词都带着“视觉锚点/站位/环境状态/布光方案”四段冗余描述，一句话就能全部清掉。
