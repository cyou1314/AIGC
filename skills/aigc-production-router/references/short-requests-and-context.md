# 短指令与上下文恢复

用户可以省略长模板。先依据本轮材料、最近明确要求和当前项目快照，恢复目标、集/板范围、交付类型、已确认平台、风格与保护项；直接完成，不要求用户每次写完表单或报Skill名。新消息的明确变更优先。

## 当前语境中的例子

| 用户短句 | 有充分当前上下文时的解释 |
| --- | --- |
| 第5集配乐 | 读取当前权威材料的第5集，沿用已确认的器乐/对白留白与平台要求，交配乐提示词；本身不等于提交音频生成。 |
| 这集给Gemini用 | 将当前音乐方案整理为Gemini同一音乐输入框可粘贴的完整英文稿，内部保留Style/Structure。若当前讨论的是其他产物，不凭Gemini一词改成配乐。 |
| 下一集也这样 | 沿用已确认的交付方式与视觉/声音体系，重新读取下一集事实；不复制上一集情节、人物出镜名单或节奏变化。 |
| 给第2—4集人物卡 | 在人物介绍卡语境中，为这些集实际出镜、值得介绍的人物写卡，保护出场时点公开信息；不扩成全剧设定。 |
| 只改第3格 | 锁定当前确认板的其他格及明确保留项，改第3格；不重排整板或重新设计剧情。 |
| 这两条接一下 | 依据当前素材检查末态/初态与接续；如果已明确要修改，则只改授权范围。只有“检查”时不自行重写。 |
| 删那四段 | 最近已明确是哪四段时，按实际标签和范围删；不知道所指时只问段名，不能凭模板默认删空间/光线锚点。 |
| 整份复制版／长文字一键复制 | 将当前选中范围的完整最终正文集中放入一个代码块，保留分段、时码、编号和必要设置；说明放块外，不改变内容锁或执行授权。 |

## 直接选择一个主分支

按“本轮要交付什么＋正在处理的对象＋当前授权范围”判断，不用单个关键词代替语义。明确专业请求不必先经过项目统筹，续做沿用当前主模块。需要明确交接时才调用另一模块，不同时启动八个模块。

| 用户表达与上下文 | 主分支与最少必要工作 |
| --- | --- |
| 第5集配乐 | 声音：读取第5集事实和已确认音乐设置，交提示词；不用先探测生成服务。 |
| 提取1—5集台词 | 声音：核对源表与集数，按原句整理；不用调用配音或重新立项。 |
| 重新设计这30秒分镜 | 导演：读选中剧情和摄影/时长锁，按授权重设计；不转成只审查。 |
| 只查这两镜穿帮／只改下一镜 | 审查：检查或修改选中范围，保留上一镜及其他锁；不扩成全片重写。 |
| 给人物卡／海报／这张只改光 | 图像：按指定交付处理人物、版式或局部光线；是否真正出图由本轮要求确定。 |
| 给剪映操作表／裁这段视频 | 后期：分别交手动操作表或执行获准的有界媒体处理；不调用剪映CLI。 |
| 写剧本／找剧情问题 | 编剧：处理剧情与获准对白；已确认剧情只缺摄影方案则由导演负责。 |
| 写产品广告／设计网页 | 商业/数字：依据真实产品事实和交付分流；发布或生成仍按实际授权。 |

专业自检留在原模块。例如检查配乐是否盖住对白仍由声音完成；独立审稿、穿帮与实片QC才交审查。“Gemini”“优化”“检查”不能脱离正在处理的对象单独决定分支。

## 分层读取，不重复启动

1. 先读当前主模块方法、本次源材料和保护项，能完成就直接交付；不用运行规划器、全目录扫描或工具预检来重复选择已明确分支。
2. 需要细节时读对应专业参考。缺具体方法、需执行原脚本或溯源时再查原文件；不默认展开完整来源索引、所有原入口或整份代码/测试资料。
3. 当前会话已读且未变的规则可复用；用户新文件、事实版本或范围变化须核对。复杂任务仍读取全部实际必要资料，完整原文继续保留，未读不称已应用。
4. 普通文字提示词无需服务或媒体工具预检；实际执行只检查该项依赖。普通制作不触发Skill改写、打包、全仓测试和同步；用户明确维护工作流才进入维护流程。

这些规则减少不必要的路由和读取，不是响应时长测量；平台排队、模型处理、附件解析和外部生成需按实际记录另行判断。

## 长稿交付边界

单份需复制使用的提示词、剧本、台词或执行文本默认一块完整正文；纯文本使用text代码块，JSON/代码保留所需格式。不能为了合并而删字、删除必要设置、压成一段或用“同上”代替内容。多集/多条独立投喂可按单元分块，平台不同输入框的字段仍清楚区分；用户要整份复制时合在一块并保留边界。超出单次输出容量就明确说明、按自然边界续接，不冒称完整。复制按钮由宿主界面提供，技能只约束输出组织。

## 沿用的边界

- 最近明确确认的平台/纯器乐策略是当前项目上下文，不自动变成所有新项目的永久事实。新项目无材料、无集数映射或同名文件版本冲突时，只定位那一项必要缺口。
- 独立配乐方案不自动解锁视频原提示词的无BGM约束；单独创作音乐与将其加入成片是不同交付。
- “来一版”“继续”“做一下”不把提示词工作自动扩大为付费生成、上传、发布、改账号或剪映CLI操作。已明确授权的可逆文字/文件操作直接推进，不额外索取重复确认。
- “修一下”结合已知问题与原锁确定局部修复；“导演重新设计”则按已授权摄影范围处理，不套只审查/最小改动模式冻结方案。
- 能从现有上下文唯一恢复就不用问。不能恢复的关键事实不假装记得。跨聊天靠可读取的快照或材料续接，不承诺所有会话自动永久记忆。

不在普通答复中复述上述映射和内部推断；直接交结果，仅在有实质影响时简短说明采用的假设。
