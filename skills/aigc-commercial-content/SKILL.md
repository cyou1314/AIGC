# AIGC Commercial Content

Select the requested deliverable: concepts, copy/script, product imagery, finished video, or a set of channel variants. Work from supplied product facts and assets. Missing facts remain unknown; claims and testimonials must have an identifiable basis.

## Production brief

Capture only what changes the work: audience/problem, one main promise, observable product evidence, tone/brand assets, requested response, available footage or product references, deliverable/format, target channel and known budget. Do not make the user fill a full form when the assets already supply the answer.

For conversion-oriented work, connect attention → evidence/use → response. Brand cinema or awareness work may instead prioritize a visual idea or emotional association. Explain which structure suits the stated goal. Respect the user's script and scope; a caption request does not become a campaign.

## Route the actual production

- Still product images, posters, carousels: `aigc-image-director` and a rendering/design tool.
- Product-only UGC explicitly requested: `ugc-product-video`.
- Explicit package opening/reveal: `ugc-unboxing-video`.
- A visible creator wearing a product: `ugc-try-on-video`.
- Creator step-by-step demonstration: `ugc-tutorial-video`.
- Creator-led service or website tour with real screenshots: `ugc-website-video`.
- Presenter-led episode: `ai-host-video` only when its production contract fits.
- Brand/dramatized ad: script as needed, then `aigc-manga-video-director` for shot work.
- Supplied clip variants: `ad-multiplier` when its length and edit constraints fit.
- Existing local draft or footage: `jianying-editing` / `auto-edit-video`; requested Higgsedit graphics: `video-editing`.

Read the selected specialist's full SKILL.md before execution. Do not load or launch all candidates. When a named plugin skill is unavailable, discover an executable alternative through the plugin tools; catalog presence is not connection proof.

## Acceptance and variants

Verify the actual visible product against references: shape, label, color, scale and demonstrated use. Check confirmed text, spoken statements, readability and the requested CTA. Observe target specs from the user or verified service documentation; never hard-code all social videos to 30 seconds.

Test one representative creative before a batch. Lock product/brand facts and vary a single creative dimension where comparison helps. Record what changed and actual production effort; do not promise conversion improvement without outcome data. Hand off clean masters and requested channel variants, with their filenames and differences.
