# 公司Seedance 2.5提示词审查

适用于已有提示词的检查、相邻分镜交接与获准局部修复，也承接 seedance-25-prompt-reviewer 的明确请求。参考用户2026-10-20提供的MIT包，保留脚本及许可证；不是新的剧情生成模板。

## 模式和权限优先

只检查就不输出替换稿；明确修改才执行。局部修复保护用户指定边界，不限制合理连带调整；导演优化可做服务剧情、清晰度和情绪的必要修改。确需调整时长或拆分已获用户常规授权，但必须保护本次明确的总长、不拆及连续锁。只改下一分镜画面时，上一条全文与下一条的非授权部分保持不变；画面栏目中的对白、声源/OS/VO标签、时间、人物/服装/道具身份和原始@标签并未因此解锁。

默认保护剧情、逐字台词、身份服装、道具存在/功能、时长、标签和本次明确拍法。原@标签逐字保留，不翻译、重排、改大小写或补造素材。允许修复持物姿态以承接真实上一镜时，不等于获准增加道具交接或改动明确锁定状态。

## 修改前确定基准与边界

- 以用户本次指定的版本为基准；未指定时使用当前项目最新确认的完整版本，区分已确认、待确认候选和实际成片。用户要求退回旧版时按其指定版本；多个版本无法识别时只问哪个版本，不能拼凑旧稿和新稿。分集、分板、条目用源身份定位，不借相邻板的内容或时长。
- 先分清用户要求、必须保留的事实和合理可变部分；“优化、自然一点”允许改善服务原剧情的机位、节奏、表演细节及必要的同稿连带调整，但不自动改写剧情结果、逐字对白、已锁资产或本次明确禁改项。按目标只改得足够好，不机械逐字冻结所有描述，也不为了优化任意扩写。用户明确只改一处时尊重更窄边界。
- 一项修改可能影响同一提示词其他位置：新站位要与出入、视线及后续动作相容；替换道具后不留旧道具的持握/声音；改为夜晚后同步调整同稿与之冲突的光线和时间描述。此类必要且不触碰硬锁的连带调整可直接做；涉及未选邻板、明确禁改项或剧情事实时先说明冲突，不为通过检查擅改。

## 修改后必须逐项复核

- **范围与时长**：先识别当前板号、完整原稿、修改范围与时长来源，避免把上一板或Excel物理行的时长挪给本板。通常保留原总长及末行写法，如 `时长：24秒`；确有必要调整或拆分时已获常规授权，更新至准确新时长，不删末行、不加“约”、不挪到复制块外。每份子提示词末尾各有时长，块外简述源长→各子条/总长及原因；明确锁总长或不拆时不得突破。
- 原稿没有末尾时长行但同板权威表格或用户给出明确整数秒时，完整提示词末尾补 `时长：N秒`，N取该板的已知值；无可靠值则标未知或询问，绝不猜。源表与原稿冲突、或原稿仅写“约”而没有精确依据时说明差异，先确认准确数值，不能把估计改称精确。用户已授权确需时调整时长或拆分；先压缩无用重复，在原时长内仍无法自然呈现关键动作、对白或反应时才调整。时间轴末点与每条时长一致，避免丢掉台词或关键动作；明确总长/不拆锁下仍无法完成则报告冲突。
- **情绪与表演**：逐角色识别原有情绪方向、强度、变化、触发和剧情作用；未授权改表演时原有情绪描述应保留。用户要求“不要太夸张”是降低幅度，不是删除情绪；让克制的情绪仍可被看见或听见，例如依据角色与情境选择视线、表情、停顿、声线中的适当证据，不把所有人物改成“面无表情”或统一套动作。涉及冲突情绪时保留层次及变化，不改对白字面。用户明确要求去掉某项情绪时遵从。
- **衔接与差异**：在本板内部逐对检查切镜，也检查可获得的上一板→本板及本板→下一板边界；邻板是只读证据，不等于获准修改。对照前镜末态与后镜初态，包括角色世界位置/朝向、视线、移动、道具持有和状态、时间及关键动作，再对比主体、实际景别/画面占比、机位角度、构图和观看信息。无意中对同一主体连续使用相近镜头时，在授权范围内按叙事目的调整景别、角度、动作细节或反应；不能只改景别标签，也不能为变化改变已锁机位或人物状态。刻意重复或连续长镜有作用可以保留；缺邻镜则标未知，不声称已检查。
- **剧情、对白与声音**：逐字核对未授权改动的台词、语言、顺序、说话者与OS/VO/电话声源；切镜不能让听者替说话人发声或多人口型同时动。保护已指定音乐/无音乐、音效、字幕和音量关系，不由“更有氛围”擅自加配乐或删除现场声音。
- **人物、道具与场景**：核对身份、出场人数、服装、身体特征、左右手、持物人、数量、物品状态及时间地点；保留精确的 `@` 标签、原有负面约束和不可见/不出现限制。检查拿出→接触→交换/使用→结果是否按原事件发生，不能为衔接平白补造交付、换手或重置物品状态。缺失信息标未知，不把通用常识写成已确认事实。
- **交付前对照**：以实际选定的完整原稿为基准，逐项核对授权范围、对白、声音、事实、资产标签、动作因果、情绪、相邻镜头和末行时长；同时查找修改后残留的旧站位、旧动作、旧时间或互相矛盾的否定词。必要但无权修复的问题要说明，不能用模糊词掩盖。用户要求完整提示词时给当前范围一个可复制的完整版本；要求局部替换时按所要求范围交付，不强行重写整份。

## 风险触发与事实提取

单条检查适用维度；缺邻条不虚构邻条。共享人物/场景、现场对白、说话者切换、OTS/反打/视线、入出场/追逐/交换位置、接续动作、左右/前后景或用户报告空间问题，触发 [相邻分镜交接](reviewer-handoff.md)。纯风景/产品/独立蒙太奇、纯画外声音等没有实际交接风险时不强制做空间审查；用户明确要求时仍检查。未做的维度标“未触发此检查器”，不能报已通过。

读取两条完整文本，依次处理转身、移动、释放、转交及切镜，提取上一条最后实际镜头、最后动作之后的末态，与下一条第一个新动作之前的初态。每项事实带原句/时间段；描述缺失标未知，裁切出画不等于消失/放手。实际已检查视频尾态优先于原计划，未看视频只称文本或用户提供状态。

区分世界位置、解剖左右手与画面投影。合法反打可改变前后景和可见正背面，不让人物转身或换手；相机角度词本身不证明跨轴。右侧出画后从左侧入画可以继续向右，不按边缘字面误判折返。合法跨轴/重建必须有实际路线或重建证据，只解释相关投影变化，不能放行服装、持手或动作重置。

多人对白逐句确认真实声源、画内/OS/VO/电话属性、可读脸、前景身份/正背面、唯一口型归属和静默听者。切看听者时原声源保持，不强制每句话反打。固定双人全景只核对归属，不强加OTS。纯VO不要求发声者露脸；对白标签本身受锁时不擅补OS，应报告冲突。

## 分类与交付

问题只分：确定冲突、需要人工判断、建议优化、未触发此检查器。缺几何不是确定越轴，摄影偏好不是错误。证据不足影响当前判断时说明具体缺项，不要求无关账本字段全满。

单条输出结论、原句证据、影响与最小修复方向；相邻触发时输出上一末态、下一初态、状态交接、关系轴/视线、触发时的对白站位和逐项问题。明确授权后才附完整下一条替换稿，上一条不重写。严格只改画面时先划定locked/visual分区，受保护字面量单独锁住，不能验失败后扩大分区。

输出区分“提示词内部一致性已检查；实际生成效果未验证”。这不是 aigc-output-qc 的实片验收结论，不能据文本发出重做媒体指令。

## 确定性辅助工具

从实际文本人工提取规范状态后，可用 Python scripts/prompt_review_checks.py dialogue|handoff|minimal-diff|visual-only --input 文件.json --json。保留原时长且已有原稿及替换稿为文本时，可用 `duration-line` 检查可复制正文末尾的原始时长行；如依常规授权调整时长或拆分，该工具对变化会报冲突，不可误当未经授权，改为核对每条准确新时长、时间轴及总长映射；输入JSON包含 `original` 和 `revised` 字符串，一板一次，只支持末行“时长：数字秒/总时长：数字秒”格式。原稿无此行或含“约”返回需人工判断；不会识别Excel来源、判断情绪、轴线、画面或证明生成效果。对普通对话手动执行相同末行比对即可，不要求为此创建文件。完整边界字段见 reviewer-handoff.md。脚本不解析原始摄影语义、不证明几何和实片，人工提取的同义状态先规范；unknown使用null，不凭空填坐标。

重要：CLI的退出码0也可能是需要人工判断或未触发，必须读取JSON的status、conclusion、issues及routing，不把退出码当全通过。minimal-diff仅验声明的替换范围；visual-only仅验人工划分锁，不证明划分本身正确。数值能力、参考上限、模型ID和API字段依当前入口另验，不沿用旧版限制。
