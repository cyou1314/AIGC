# 分镜表的指定段落裁剪

适用：用户明确要求删除分镜提示词中某些独立说明行，保护其余文字和其他列。与一般“优化/精简/更专业”分开，不能未经说明就删视觉锚点、站位、环境状态、布光方案；这些信息可能是唯一连续性依据。原来源写Seedance 2.0 Mini仅是使用背景，当前工作流仍为2.5；本任务是表格文字变换，不涉及切换生成模型。

先确认权威工作簿、工作表、提示词列、目标行与明确标签。最近已确定的“那四段”可直接解析，不让用户重复长指令；范围不明时只问那项。原文件保留，输出新副本。纯聊天文字按同一精确范围处理，不必硬套脚本。

## 吸收与修正

保留来源的预检、源备份思想、指定标签/行选择与逐格验证；不直接采用来源脚本的就地覆盖模式。代码审阅发现：它还压缩所有三连空行，所谓复原校验实际上重复运行同一转换，其他列检查仅覆盖计划行并以data_only读公式，changed是计划行数，部分校验失败发生在写回后。因此原包归档保留，不将其ok=true当成所有文字/工作簿无损证据。

当前本地助手仅支持可安全往返的纯文本xlsx：明确标签开头、画面段之前的独立单行说明。保留非删除行的原始空白和换行，不额外压缩；多行延续、同一行混入保护段、画面/对白内同名内容不猜删。只在当前材料明确批准了目标段时执行，不把程序参数当用户授权。

带公式、宏、外部链接、图片/图表、透视表、扩展对象或无法保证保留的工作簿不自动保存；可以仍交只读删除清单，或用用户已有的原生表格编辑能力处理。不要通过pandas重建整张表冒充仅改目标格。

交付前对新文件实际重开：所有工作表、行列、单元格类型/值、基本样式、合并区域、筛选/冻结与超链接等保护属性不变，只有批准的目标单元格允许精确删除。源SHA256不变；实际变化数、命中标签、剩余可疑标签和检查范围如实报告。零命中不算改好；先核对标签的半/全角冒号和所用版本。

本地运行入口在本Skill的scripts/trim_prompt_sections.py；默认只预检，--write要求新输出路径。插件运行助手可转交相同操作。输出文件成功不代表删除后仍满足完整导演语义；原空间/声音锚点是否已在画面保留，需要相应专业检查。
